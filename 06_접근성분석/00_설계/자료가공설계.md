## 3. 가공 단계

### P1 격자 마스터 `grid-master-100m-v1` · `grid-master-250m-v1` — 완료·확정

- 입력: SGIS `grid_다사_100M.shp`(82만 셀, EPSG:5179) + 통계 CSV(인구·가구·사업체·종사자 2019·2024).
- 결과: 100m 60,528셀(인구 2019 9,642,246 / 2024 9,337,885), 250m 9,774셀(Σpop 100m와 같음). 열: grid_cd, 중심 x/y, pop/hh/biz/emp_{2019,2024}, dong424, ku, lz116, ld2020, ld2025.
- 250m: 국가격자체계 250m 셀 기하만 사용(원점이 SGIS와 같음). SGIS 100m 인구를 면적비로 배분해 합산. 그 파일의 인구값·승훈 OD는 쓰지 않음.
- 주의: SGIS 소수값 보호(5 미만 0/5 무작위, ±7 잡음) → 합계는 서울 총인구와 +0.06% 이내. 논문에 (a) 서울 고밀, (b) 합계 일치, (c) 인구가중 비율 지표, (d) 250m 민감도를 적는다. 100m에는 연령 없음 → 집계구 코드만 부착(연령 배분 보류).

### P2 분석용 시설 `facility-v1` — 완료·확정

- 분석용 606,072행, 33종 = 신뢰도 상 32 + 일상소매(중, 조건부). 단위 표 `facility_2020_2025_units.parquet`: dong424, ku, lz116, ld2020, ld2025, cat_A, cat_A4, cat_B, tau_B_min, role, grid100_cd, grid250_cd.
- 카테고리: `cat_A`(기능 카테고리 8개, 28종) / `cat_B`(국가 최저기준 마을단위 5개 + τ) / 통제 5종(버스정류장·지하철역·따릉이·주유소·노인 입소시설). 구성은 `지표정의_확정.md` 2절.
  - 연구1은 공공도서관을 단일 시설 실험의 주 시설로 따로 쓴다.

### P3 보행 네트워크 `network-walk-v1` (2020·2025) — 완료·확정

- 입력: Geofabrik `south-korea-200101.osm.pbf`, `south-korea-250101.osm.pbf`. 서울 경계 + 2km 버퍼, 보행 가능 도로·보도만. 속도 4.0km/h.
- 결과: 2020 338,915노드/12,562km, 2025 586,959노드/16,533km. **+31.6%는 대부분 OSM 매핑 증가** → 2020→2025 변화 해석의 한계로 명시.

### P4 보행 소요시간표 `ttm-walk-v1` (100m·250m × 2020·2025) — 완료·확정

- 격자→격자, 30분(1,800초) 이내만 저장. 열 o_grid, d_grid, t_sec(uint16), 출발 구 ku로 Hive 분할. 4.0km/h. 100m 22,082,441 / 22,625,482쌍, 250m 725,618 / 749,529쌍. 청크 결합 해시는 P5에서 재계산해 일치 확인.

### P5 공통 접근성 엔진 `access-engine-v1` — 완료·확정 (2026-09-24)

- 코드: `06_접근성분석/02_scripts/a06_engine.py`(엔진), `a06b_summary.py`(요약), `tests/test_engine.py`(단위시험), `run_engine.bat`(PC 재현용).
- 격자 비트마스크 C_g(같은 카테고리 중복은 비트 하나), 출발(인구>0) × 경계 b ∈ {none, dong424, lz116, ld(해당 연도), ku} × 카테고리: r, m(조건부), 최근접 시간(30분 상한), 선택 시 합집합 U(Nicoletti). 묶음 B는 시설별 τ·경계 없음·하위유형 OR.
- 집계: 모든 상위 단위는 분자합/분모합. MAI·PWATT 분모는 도달 인구. 종합 COV = 8개 단순평균, 종합 MAI = 값 있는 카테고리 단순평균.
- 검증: 단위시험 10/10 — 연구3 7.1 예제 1(LZ COV 1/0.667/0 종합 0.556, MAI 1.667/2/정의 안 됨 종합 1.833; LD 모두 1·3), 예제 3(59/110), PWATT 손계산, 중복 시설, 속도 환산, 묶음 B, 경계 단조성, 종로구 실자료 pandas·DuckDB 독립 구현 완전 일치(강남구 2020·노원구 250m 추가 대조도 일치). 14개 실행 불변조건 통과.
- 실행 세트: main, sens_T600, sens_speed36, sens_grid250, sens_A4, sens_retail_without, sens_union, natstd_B. 체육 "규칙 없음" 민감도는 분석용 파일에 해당 행이 없어 불가, 면적비 배정은 연구1 전용으로 범위 밖.
- 산출물: `03_output/{tag}/grid_access_{year}_{grid}.parquet`, `unit_access_{year}_{grid}.csv`, `natstd_B/nat_standard_coverage_{year}_100.csv`, `summary_{tag}.md`, `03_output/summary_sensitivity.md`. 연구별 분석은 이 표를 읽기만 한다.
- 주요 값(서울, 종합, 2020→2025): COV 경계 없음 0.960→0.965, 공식 LZ 0.941→0.948, Leiden 0.943→0.948 / MAI 4.74→4.73, 4.58→4.57, 4.57→4.56 / PWATT 3.9→4.0분. 동별 ΔCOV(LD−LZ) 평균 +0.0005·+0.0003, ΔMAI −0.013·−0.012. 묶음 B 종합 0.959→0.946(어린이집 5분 0.876→0.817). 논문 인용은 반드시 `03_output` 파일에서.

## 4. 공통 정의 (`지표정의_확정.md`가 유일한 출처)

| 항목 | 정의 |
|---|---|
| 보행 속도·임계 | 4.0km/h, T = 15분(900초) 본분석, 10분(600초)·3.6km/h 민감도, 도달시간 상한 30분 |
| Coverage | T 이내(경계 조건 시 같은 단위 안) 해당 카테고리 도달 인구 / 단위 전체 인구. 종합 = 8개 단순평균 |
| MAI | 도달 가능한 해당 카테고리 격자 중 최대 동시입지 카테고리 수, 도달 인구만 분모(조건부). 종합 = 값 있는 카테고리 단순평균(D2 확정) |
| 도달시간 | 카테고리별 최근접 보행시간(30분 상한), 단위 값은 15분 내 도달 인구의 인구가중 평균(PWATT) |
| 묶음 B | 국가 최저기준 5개, 시설별 τ, 경계 없음, Coverage만 |
| 격자·시설의 단위 번호 | 격자 중심점·시설 점 → 동 424 → 생활권(모든 경계 동일 규칙) |
| 시점 대응 | 2020 = 시설 2019-12-31 · 인구 2019 · 네트워크 2020-01 / 2025 = 시설 2024-12-31 · 인구 2024 · 네트워크 2025-01 |
