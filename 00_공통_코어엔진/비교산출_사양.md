## 2. 정의 (연구2 확정안 그대로. 허브 확정본이 다르면 확정본을 따른다)

- **IFR**: 권역 c에서 출발한 통행 중 c 안에서 끝나는 통행 비율. 방향 OD, 출발지 기준, 동 내부통행 f_ii를 분자·분모에 포함, 분모 = 출발이 c인 서울 내 모든 통행. 필터는 od_daily에 이미 적용됨(도착 09~20시, HW·WH 제외, 전 요일). 구·서울은 분자합/분모합.
  - 점검: 같은 구에서 공식과 Leiden의 분모가 같아야 한다(연구2 R6) → 다르면 중단.
  - 이 값은 s03·s05의 구별 IFR과 같아야 한다(5 참조).
- **Q**: 구 내부 무방향 그래프 a_ij = f_ij + f_ji, 자기 루프 간선 가중치 f_ii(행렬 A_ii = 2f_ii), γ = 1. s03 `modularity_q` = python-louvain 정의와 같다(s05에서 차이 0 확인). 구별 Q는 평균하지 않고 분포로 보고.
- **IoU_1to1 (주)**: 구 안에서 공식 생활권 × Leiden 교차표(동 개수)를 만들고 교집합 합이 최대가 되도록 1:1 배정(`scipy.optimize.linear_sum_assignment`). 권역 값 IoU_z = |z∩π(z)| / |z∪π(z)|. 구 값 = S / (2N − S), S = 배정된 교집합 합, N = 구의 동 수. 연구4 `iou_1to1`과 같은 식.
- **IoU_JTG (보존)**: 공식 생활권 z마다 IoU가 최대인 Leiden c를 고름(다대일 허용, 동점은 Leiden 번호가 작은 쪽). 구 값 = Σ교집합 / 구 동 수. 게재본 `250512_calculate_iou.py` 방식.
- **ARI**: 구별, 공식 vs Leiden (s05와 같은 함수).
- 면적 IoU(EPSG:5179)는 민감도로만.
