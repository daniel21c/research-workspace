# 생활권 최적화 검증 — 설계 (2026-09-24, 초안)

## 0. 질문

지금까지는 "116 고정이 타당한가"를 물었다(방어). 이 설계는 반대 방향을 묻는다.

> **생활권을 이동 자료로 최적화하면 실제로 어떤 경계가 나오고, 공식 생활권과 무엇이 달라지며, 그 변화는 얼마나 의미 있는가?**

답은 논문 결론 장의 "생활권계획을 어떻게 개선해야 하는가 → 바꾸면 이렇게 된다"의 근거가 된다.
정본(116, 1:1 비교)은 그대로 둔다. 여기서 만드는 것은 **제안 경계**다.

## 1. 원칙

1. "최적"은 하나가 아니다. 무엇을 목표로 두느냐(계획 원리)에 따라 답이 다르다. 그래서 원리별 시나리오를 미리 정해 두고 같은 잣대로 비교한다. 결과를 보고 시나리오를 고르지 않는다.
2. 개수가 다른 경계는 IFR 원값으로 비교하지 않는다(개수가 적을수록 IFR 은 기계적으로 커진다). 같은 개수의 무작위 경계 대비 **초과 자족성(z)** 을 주 지표로 쓴다.
3. 모든 시나리오에서 반복되는 변화만 "확실한 제안"으로 올린다. 한 시나리오에서만 나오는 변화는 "원리에 따라 달라지는 선택"으로 적는다.
4. 계산은 PC 에서 사용자가 실행한다. 정본 폴더는 읽기만 한다. 결과는 `output/proposal/` 에 쓴다.

## 2. 시나리오

| 코드 | 계획 원리 | 개수 결정 | 경계 생성 | 이미 있는 것 |
|---|---|---|---|---|
| **P0 공식** | 현행 계획 | 구별 공식 수(116) | 서울시 생활권 경계 | 정본 |
| **P0' 정본** | 현행 개수 + 이동 경계 | 116 | Leiden 합의(정본) | 정본 |
| **P1 구조** | "이동 구조가 스스로 고르는 개수" | 구별 Q 최대 개수(B1: 106 / 111) | Leiden 합의, 정본 파이프라인 `--targets` | 개수만 있음 → **s03 재실행 1회** |
| **P2 자족성 규칙** | 영국 TTWA: 모든 권역이 자족성 문턱을 넘어야 한다 | 문턱 SC*=0.25 를 두 해에 같이 적용 → 개수는 결과(103 / 135) | TTWA 병합 | x6 라벨 있음 |
| **P3 인구 규칙** | 계획단위 인구 하한(공식 생활권의 원리) | 하한 7만 명 → 개수는 결과(116 / 107) | max-p | x7 라벨 있음 |
| **P4 구 경계 해제** | 구 행정경계를 무시한 이동권 | 서울 전체 Leiden, k≈116 | x8 | 라벨 있음 (참고용) |

- P1 은 "데이터가 스스로 고른 개수"의 가장 단순한 정의이고, 정본과 같은 파이프라인이라 경계 차이가 개수 차이만 반영한다.
- P2 는 두 해에 **같은 규칙**을 쓰므로 2020→2025 의 개수 변화(국지화)가 그대로 드러난다.
- P3 은 공식 생활권이 따르는 원리를 이동 자료로 재현한 것 — "공식 개수는 인구 규칙의 결과"라는 해석의 검증.
- kmob_lo/hi(4개 방법 중앙값)는 원리가 섞여 있어 시나리오에서 빼고 민감도 부록에만 둔다.
- P2 의 문턱 0.25 는 두 해 합계가 116 양쪽에 걸치는 값이다(0.225→122, 0.275→123 이 각 해의 116 근사). 문턱 0.20·0.30 도 같이 표로 내어 결론이 문턱에 흔들리는지 본다.

## 3. 비교 잣대 (모든 시나리오 × 두 해, 구별 + 서울)

| 축 | 지표 | 뜻 |
|---|---|---|
| 개수 | k(구별·합), 공식 대비 ± | 얼마나 더/덜 나눴나 |
| 자족성 | IFR 원값, **초과 자족성 z·백분위**(같은 k 의 인구 균형 무작위 경계 500개 대비, x2 방식) | 개수 효과를 뺀 자족성 |
| 구조 | Q, 귀무모형 대비 z(x4 기준선) | 이동 구조를 얼마나 설명하나 |
| 인구 균형 | 권역 인구 CV, 최소·최대 권역 인구, 동 1개짜리 권역 수 | 계획단위로 쓸 만한가 |
| 공식과의 거리 | ARI(공식), 바뀐 동 수, 구별 "분할/병합/재배치" 분류 | 무엇이 달라지나 |
| 시점 | 2020→2025 IFR·z 변화, 두 해 경계 ARI | 개선안이 시간에 안정적인가, 국지화가 보이나 |

- 무작위 기준선: x2 의 `random_curve.csv`(구·k·귀무별 평균·표준편차)를 재사용, 없는 k 는 같은 시드로 추가 생성.
- P4 만 구별 지표가 없고 서울 지표만 낸다.

## 4. 산출물

1. `output/proposal/scorecard.csv/.md` — 위 잣대 표 (시나리오 × 연도 × 구, 서울 합계)
2. `output/proposal/changes_{year}.md` — 구별로 "공식 → P1/P2/P3 에서 무엇이 바뀌나": 분할(어느 권역이 어떻게 나뉨), 병합, 동 이동 목록
3. `output/proposal/robust_changes.md` — **세 시나리오 모두에서 같은 방향**인 변화 목록 = 확실한 제안 후보
4. 지도: 구별 소지도(공식 | P1 | P2 | P3, 두 해) 25장 + 서울 전체 1장. 색은 권역, 굵은 선은 공식 경계와 다른 곳
5. 결론 장 초안 문단: "개수 · 경계 모양 · 시점 · 구 경계 · 설계 원리" 다섯 꼭지

## 5. 실행 순서 (PC)

## 6. 미리 정해 두는 해석 규칙 (결과 보고 바꾸지 않음)

- 어떤 구가 "더 나눠야 한다"고 말하려면: P1·P2 둘 다 공식보다 많고, 초과 자족성 z 가 공식보다 높아야 한다(P3 은 인구 원리라 방향 판단에서 제외, 균형 확인용).
- "합쳐도 된다": P1·P2 둘 다 공식보다 적고, 합친 뒤 z 가 낮아지지 않아야 한다.
- 공식 개수를 유지해도 되는 구: 위 어느 쪽도 아닌 구. 이 구들은 "개수가 아니라 경계 모양"이 개선점이다(정본 vs 공식 ARI 로 크기 표시).
- 시점: P2 의 두 해 개수 차이가 국지화 지표. 이 차이가 특정 구에 몰리는지 본다.
- 인구 균형이 공식보다 크게 나빠지는 제안(권역 인구 CV 가 0.4 를 넘거나 동 1개짜리 권역이 생기는 구)은 "이동 구조상 근거는 있으나 계획단위로는 보완 필요"로 표시한다.

## 7. 정한 것 (2026-09-24, 사용자)

- (a) P1~P3 을 나란히 두고 같은 잣대로 비교한다. 세 안에서 공통으로 반복되는 변화만 "확실한 제안"으로 올린다.
- (b) 지도는 25개 구 전부 + 서울 전체 1장. 논문에는 골라 쓰고 나머지는 부록.
- (c) 이중 목표(자족성 + 인구 하한) 시나리오는 이번에 넣지 않는다. P1~P3 결과에서 자족성 높은 안이 인구 균형을 크게 해치면 그때 설계한다.
