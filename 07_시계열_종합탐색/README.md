# 07 시계열 종합 탐색

- 목적: 확정 배포본(경계·OD·시설·격자 인구·접근성 엔진 결과)을 한 번에 겹쳐 2020→2025 변화를 탐색하고, 논문(연구1·3·4, 5장)에 쓸 발견 후보를 근거와 함께 목록화한다.
- 담당: 시계열 종합 탐색 대화(시작 프롬프트 [_prompts/07_시계열_종합탐색.md](../_prompts/07_시계열_종합탐색.md))
- **이 폴더의 수치는 탐색용이다.** 논문에 쓰려면 해당 연구 폴더가 자기 설계에 맞춰 재계산·검증한다.

## 파일

- `탐색보고서.md` — 결과(0절 요약, 2절 질문별, 3절 순위표, 4절 결정, 5절 다음 질문)
- `작업기록.md` — 날짜별 기록, 허브에 올릴 제안
- `scripts/x01_load.py` 결합 → `x02_checks.py` 점검 → `x03_questions.py` Q1~Q9
- `output/tables/` 패널·질문별 표·`criteria.json`(사전 판정 기준)·`q_results.json`·`sources_manifest.json`(입력 해시)
- `output/figures/` F1~F9

이 폴더 밖의 파일은 읽기만 한다. 규칙은 [저장소 README](../README.md)를 따른다.
