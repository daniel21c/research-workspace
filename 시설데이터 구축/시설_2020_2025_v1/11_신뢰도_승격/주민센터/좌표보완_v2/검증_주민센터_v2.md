# 검증 — 주민센터 좌표보완 v2 (2026-09-24)

## 목적
v1(검증_주민센터.md)에서 남은 미해결(2020_01 22곳 / 2025_01 5곳)을 **기준일 당시 청사 위치**로 채워 S(공간) 조건을 다시 판정한다. T·D는 v1 결론(행정동 수 424/426 = 목표일 공식 수, 구별 완전 일치) 그대로.

## 방법 (행별 근거는 fill_log_주민센터.csv)
1. 청사 이전 이력 확인: 구청 공지·지역신문(신청사 착공/개청일, 임시청사 이전일)으로 2019-12-31·2024-12-31에 어느 건물에 있었는지 판정.
2. 좌표: 옛 도로명 주소가 현재 주소DB에 없으므로 **당시 지번**을 찾아 Kakao 지번 검색(번지 정확 일치, VWorld 보조)으로 좌표. 지번은 VWorld 검색API(place)의 옛 POI(도로명·지번이 명부 주소와 같은 기록), zip.nett.kr 건물정보 등에서 확인.
3. 두 번째 근거: POI 좌표·인접 건물번호(같은 도로의 ±번호 건물이 30~60m 안), korea724 등록 좌표, 행안부 20201231/20251231판 주소.
4. 공간 열(x_5179, y_5179, inside_seoul, adm_dong_cd, oa_cd, grid100_cd)은 원 빌드와 같은 `fac.attach_geo`로 채움. 채운 20행 모두 좌표가 떨어진 행정동 = 센터 이름의 동.
- coord_method='search_verified', coord_stage='filled_v2', 추가 열: coord_evidence_url, coord_second_source, coord_v2_how, coord_v2_addr_used, coord_confidence, coord_v2_note.
