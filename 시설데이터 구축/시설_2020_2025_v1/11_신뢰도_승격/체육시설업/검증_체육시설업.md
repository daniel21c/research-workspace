# 검증 — 체육시설업(민간 신고·등록 체육시설업) (2026-09-24)

## 1. 적용 방법
1 공식 통계 대조 / 2 범위 제한(정의 맞춤) / 4 민감도(시나리오 A·B·C) — 좌표는 원 빌드가 이미 기준 충족(3 불필요).

## 2. 공식 통계
- 문화체육관광부 「전국 등록·신고 체육시설업 현황」
  - 2019.12.31 기준: 「2020년 전국 등록·신고 체육시설업 현황」(등록 2021.03.29) https://www.mcst.go.kr/site/s_policy/dept/deptView.jsp?pSeq=1468&pDataCD=0417000000 → `raw/mcst_체육시설업현황_2019말.pdf`, `raw/page_1468.html`
  - 2024.12.31 기준: 「2025 전국 등록·신고 체육시설업 현황(2024년 말 기준)」(등록 2026.03.11) https://www.mcst.go.kr/site/s_policy/dept/deptView.jsp?pSeq=2115&pDataCD=0417000000 → `raw/mcst_체육시설업현황_2024말.pdf`, `raw/page_2115.html`
- 서울 합계: 책자 '서울 총괄현황(2) 신고체육시설업' 표. 구별: 체력단련장·당구장·체육도장은 책자 구별표, 그 외 업종은 업소 목록 소재지의 자치구 토큰 계수(`raw/mcst_seoul_gu_parsed.csv`, `scripts/parse_mcst_pdf.py`).
- **주의: 2019말 책자에는 서울 중구 자료가 없음**(구별표·목록 모두 중구 0/누락). 따라서 2020_01은 **중구 제외** 비교가 정의가 맞는 비교다. 2024말 책자는 25개 구 모두 포함.
- 비교 업종 7종(당구장·체력단련장·체육도장·골프연습장·수영장·종합체육시설·빙상장). 2024 책자의 '가상체험 체육시설업'(서울 896)은 구축본에 없는 업종이라 제외(두 시점 동일 정의).

## 3. 시나리오(두 시점에 같은 규칙)
- A 전체: 원 빌드 그대로.
- B 일괄말소 제외: `flag_bulk_admin_end`(같은 업종·같은 종료일 20건 이상 직권 취소·말소) 행 제외.
- C 취소·말소 상태 전체 제외: 현재 상태가 취소/말소/만료/정지/중지(`flag_admin_end`)인 행 제외. 직권말소는 실제 폐업이 신고 없이 훨씬 전에 일어난 경우가 대부분이라 기준일 운영 여부가 불확실한 행을 모두 뺀 규칙.

## 7. 최종 판정: **상 (규칙 C 적용 시, 7업종 합계 기준)**
- T: C 규칙에서 서울 합계 2020 −2.08%(중구 제외 정의 맞춤), 2025 +4.75% → 두 시점 모두 ±5% 이내. 구별 r 0.955 / 0.974.

- S: 좌표율 99.2% / 99.5%, 85% 미만 구 없음.
- 원 빌드 그대로(A)는 2020 +12.75%(중구 제외)로 **중** 유지 — 반드시 `scope_flag == 'C포함'` 만 사용.

## 8. 남은 문제
- 업종별로는 ±5%를 넘는 업종이 있음(2025 체육도장 +8.1%, 골프연습장 +7.5%, 수영장 +8.5%, 종합체육시설 +10.1%, 2020 체력단련장 −7.6%). 업종별 분석은 '중' 수준으로 해석하고 민감도(A/B/C) 병기 권장.
- C 규칙은 '기준일 뒤에 실제 운영하다 취소된' 행도 빼므로 2020을 약간 과소(−2%)로 만든다. B(+3.6%/+5.7%)와 C 사이가 참값 범위.
- 2019 책자에 중구가 없어 2020 중구는 공식 대조 불가. 2025 중구 편차(+104%)도 큼 → 중구 단독 해석 주의.
- 구 단위 편차가 2020에 큼(최대 ±30%대). 구 단위 비교 결론은 두 시나리오로 확인할 것.
