# 검증 — 공공체육시설 (2026-09-24)

## 1. 적용 방법
1 공식 통계 대조(구축본 = 공식 명부 파싱, 종목별 일치 확인) / 2 범위 제한(두 시점 같은 종목만 '핵심종목') / 3 좌표 추가 보완(한강공원 시설지도, 엄격 규칙) + 구 단위 결측 편중 검사 / 도시재생 기본방침 별표2 분류.

## 2. 공식 통계 (T)
- 문화체육관광부 「전국 공공체육시설 현황」 2019.12.31 기준(총괄 + 마을체육시설 파일), 2024.12.31 기준(종합본). 원본은 `02_명부/공공체육시설/raw/`(메타데이터에 URL·sha256).
- 구축본은 명부의 서울 개별시설 행 그대로: 2019말 **529** / 2024말 **716** = 명부 서울 집계와 종목별 모두 차이 0 (`official_compare_공공체육시설.csv`). 간이운동장(마을체육시설)은 좌표 없는 구 집계표만: 2,476 / 2,538.
- → T 충족(두 시점 모두 공식 기준일 자료).

## 4. 좌표 (S)
### 추가 보완: 미래한강본부 한강공원 시설지도
- https://hangang.seoul.go.kr/www/facility/map.tab?opt2=SPORTS&opt3=DM_SPORTS (목록 레이어 `/www/facility/mapList.layer`, robots.txt 없음) → 체육시설 124곳(이름·주소·위경도, 현재판) `raw/hangang_sports_facilities_20260924.csv`
- 엄격 규칙: 명부 이름에 한강공원 지구명 + 이름 핵심어가 종목명과 정확히 같음 + 시설지도 이름(괄호 앞, 지구명·번호 제거)이 같은 종목명 + 번호 겹침 + 좌표의 자치구 = 명부 자치구 + 후보 1건(또는 모두 300 m 안). `coord_method=borrowed_hangang_facility_map`.
- 채택 **8행/시점**(뚝섬·망원·광나루 축구장, 뚝섬·망원·여의도·광나루 게이트볼장). 미채택: 이촌 축구장1·2(시설지도에 번호 없는 1곳), 이촌 축구교육장(이름 불일치), 망원·광나루 야구장(임시)(시설지도에는 '어린이/성인야구장'), 한강 테니스장 3곳(시설지도 체육시설 목록에 없음), 강서 축구장·잠실 게이트볼장(후보 없음). 로그 `hangang_fill_log_공공체육시설.csv`.
- 서울 열린데이터광장에는 한강공원 체육시설 '좌표' 데이터셋을 찾지 못함(OA-21779는 좌표 열 없음 — 원 빌드에서 이미 사용).

### 결측 편중 검사
- 자치구 × 좌표 유무 카이제곱: 2020 χ²=39.6(df 24) **p=0.023**, 2025 χ²=59.6 **p=7×10⁻⁵** → 좌표 결측이 구별로 고르지 않음.
- 종목 × 좌표 유무: 2020 p=0.002, 2025 p=4×10⁻¹⁴ (게이트볼장 61%, 기타(그외) 60%, 롤러스케이트장 64%, 투기체육관·하키장·싸이클 0% vs 수영장 96%, 생활체육관 94%).
- → 점(좌표) 단위 접근성 분석은 구·종목별로 편향. 구 단위 집계는 자치구 값이 전 행에 있으므로 편향 없음.
- 구별 표: `coord_by_gu_공공체육시설.csv`

## 6. 최종 판정
- **핵심종목(15개 종목, 서울 소재): 상(구 단위)** — T 공식 명부 기준일 두 시점, D 같은 종목·같은 규칙, 모든 행에 서울 자치구 있음. S 미충족(좌표율 80~82%, 엄격 65~69%, 85% 미만 구 13~20개, 결측이 구·종목별로 편중).
- 기타체육시설·파크골프장 포함 전체: **중** — 2024 명부의 범주 확대로 두 시점 정의가 같다고 보기 어려움(구 단위로도 변화량 과대).
- 간이운동장(마을체육시설): 구 집계표만 있어 원래부터 구 단위 자료(두 시점 공식 표) — 구 단위 사용 가능.

## 7. 남은 문제
- 명부 주소 공란 95/113행은 명부만으로는 정확 좌표화 불가. 자치구 시설관리공단 누리집·서울시 공공서비스예약 시설 주소 등으로 개별 확인하면 개선 여지.
- 원 빌드의 키워드 검색 좌표(78/90행)는 엄격 규칙 밖 — 점 단위 분석에 쓸 때는 `coord_strict` 로 민감도 확인.
- 서울 밖 소재 행 처리(분석 제외)는 연구 목적(자치구가 공급하는 시설 vs 서울 안 입지)에 따라 바꿀 수 있음.
- 골프연습장·국궁장의 거점/마을 구분은 별표2에 직접 예시가 없어 연구자 판단.
