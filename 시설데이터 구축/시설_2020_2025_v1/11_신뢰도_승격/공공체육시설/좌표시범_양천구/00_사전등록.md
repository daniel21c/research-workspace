# 공공체육 핵심종목 좌표 보완 — 양천구 시범 사전등록 (2026-09-25)

스크립트를 돌리기 전에 적은 규칙이다. 결과를 본 뒤 규칙을 바꾸면 이 문서 끝의 "변경 이력"에 남긴다.

## 1. 왜 양천구인가
- `../좌표보완_v2/coord_by_gu_공공체육시설_v2.csv` 기준으로 두 시점 모두 엄격 좌표율이 85% 미만(50.0% / 55.2%, 2025 최저 구)이다.
- 행 수가 26 / 29행으로 한 구 시범에 알맞고, 결측 유형(안양천 둔치 시설, 명부 주소 공란, 청소년수련관 부속시설, 이름 바뀐 시설)이 서울 전체 결측 유형을 대부분 포함한다.
- 공개: 구를 고르기 전에 양천구 행 목록과 OA-21779 양천구 행을 먼저 훑어봤다(완전한 맹검 시범은 아님).

## 2. 입력
- `../좌표보완_v2/facilities_공공체육시설_{2020,2025}_01.parquet`에서 `scope_flag='핵심종목'`이고 `gu_seoul='양천구'`인 행.
- 공식 목록: `02_명부/공공체육시설/raw/seoul_OA-21779_공공체육시설정보_현재.csv`(서울 열린데이터 OA-21779, 2026-09 현재판, SHA-256 13216ca9…). 새로 내려받지 않는다.
- 원본 폴더(01_·02_·03_·10_)는 읽기만 한다.

## 3. 방법 (순서 고정)
- **0 검증 강화(자치구 일치):** 기존 엄격 좌표(`coord_valid_v2=True`)도 좌표의 자치구(행정동 코드 앞 5자리)가 명부 자치구와 다르면 `gu_mismatch`로 무효 처리하고 1~3단계 대상에 넣는다.
- **1 주소 정제 + 건물번호 일치 재지오코딩:** 명부 주소가 있는 미해결 행(키워드 좌표 행 포함)을 `coord_fill.normalize_variants`로 정리하고 `mb.geocode`(도로명+건물번호 또는 지번 번지 정확 일치, Kakao → VWorld)로 다시 조회한다. 좌표가 양천구 안이어야 채택한다. 도로명 종류를 바꾸는 추정(예: ~길 → ~로)은 하지 않는다.
- **2 공식 목록 대조(OA-21779):** 같은 자치구 안에서 다음 순서로 1건만 남을 때 그 목록 주소를 1단계 규칙으로 지오코딩한다.
  - R1 정규화 명칭 완전 일치 + 종목 호환(원 빌드 2b 규칙, `coord_fill.TYPE_OK`)
  - R2 명칭 포함: 명부 이름의 핵심 토큰(`v2lib.core_tokens`, 끝 번호 제거)이 모두 목록 이름에 들어 있고 종목 호환. 후보가 여러 건이어도 주소가 모두 같으면 1건으로 본다.
  - R3 소속 건물: 명부 이름이 "<소속 건물> + 종목어"(`v2lib.host_of`가 `host_building`)이고, 목록에 소속 건물명과 정규화 명칭이 같은 행이 1건.
  - 목록 주소는 현재판이다. `coord_time_basis='current_list'`로 적는다.
- **3 두 시점 연결:** 같은 `facility_id`가 다른 시점에서 0~2단계로 엄격 좌표를 얻었고, 두 시점 명부 주소가 같거나 한쪽이 공란이면 그 좌표를 쓴다.

## 4. 두 번째 근거(정확도 확인)
- 새로 채운 모든 행에 `v2lib.search`(이름·구·종목만 쓰는 Kakao 키워드 검색, v2와 같은 규칙)를 돌려 시설 POI와의 거리를 잰다.
- 채택 규칙:
  - 두 번째 근거가 **250 m 안** → `verified`
  - 두 번째 근거가 없음 → 건물형 시설(수영장·생활체육관·구기체육관·투기체육관·빙상장 또는 R3 소속 건물)만 `address_only_building`으로 채택. 공원·둔치형(축구장·야구장·테니스장·게이트볼장·롤러스케이트장·국궁장·육상경기장·골프연습장 등)은 채택하지 않음(`unverified_open_site`).
  - 두 번째 근거가 **250 m 밖** → 채택하지 않음(`conflict`).

## 5. 판정 기준
- 양천구 핵심종목 엄격 좌표율이 **두 시점 모두 95% 이상**이고 채택 행 중 `conflict`가 없으면 → 시범 통과. 서울 전체 적용안(등급 상향안)을 쓴다. 상향 여부는 서울 전체 적용 뒤 작업지침 S 기준(서울 ≥95%, 85% 미만 구 없음)으로 다시 판정한다.
- 미달이면 → 공공체육 핵심종목은 **민감도용(신뢰도 중)** 으로 둔다. 개선 폭과 남은 결측 유형만 기록한다.

## 6. 부수 점검(판정과 별개)
- 서울 전체 기존 엄격 좌표 중 좌표 자치구 ≠ 명부 자치구인 행을 센다(0단계를 서울 전체에 적용했을 때 좌표율이 얼마나 줄어드는지).
