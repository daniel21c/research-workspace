## 기본 사용
```python
import pandas as pd
f = pd.read_parquet('서울시설_2020_2025_분석용.parquet')
f = f[f['분석가능']]                              # 서울 안 + 좌표 있음
village = f[f['국가기준_구분']=='마을단위']          # 도보 생활권 지표(Coverage·MAI)
hub     = f[f['국가기준_구분']=='지역거점']          # 차량 기준 지표
t2020, t2025 = f[f.year==2020], f[f.year==2025]
```
- 좌표계: `x_5179, y_5179` = EPSG:5179 (SGIS 격자와 같음). `lon, lat` = WGS84.
- `grid100_cd` = SGIS 100m 격자 코드('다사' + x 3자리 + y 3자리). `adm_dong_cd` = 행정동(426개), `oa_cd` = 집계구 — **두 시점 모두 SGIS 2025_2Q 경계**로 결합(SGIS 2019·2024 인구통계도 2025_2Q 경계로 재집계되어 있어 수요와 같은 경계).

| year / 기준일 | 2020 = 2019-12-31, 2025 = 2024-12-31 |
| 시설 / 시설_세부 | 33개 시설명 / 세부 유형(종별·업종·학교급 등) |
| 국가기준_구분 | 마을단위 / 지역거점 / 보조 — 제2차 국가도시재생기본방침 별표2 기초생활인프라 기준으로 분류 |
| 국가기준_시설 / 국가기준_접근시간 | 별표2의 시설명과 최저기준 시간(예: 어린이집 도보 5분, 보건소 차량 20분) |
| 신뢰도 | 상 / 조건부 상(체육시설업: 현재 취소·말소 상태 제외 규칙, 주유소: 휴업 제외·인접연도 대조) / 중(조건부 채택: 일상소매) |
| inside_seoul / 분석가능 | 서울 안 좌표 여부 / 분석에 쓸 수 있는 행(서울 안 + 좌표 있음) |
| coord_method | 좌표 방식(원천 좌표 변환, 주소 지오코딩 정확일치, search_verified 등) |
| grade | 원천 시점 등급 A(기준일 배포본)·C(연간 명부)·B(이력 역산) |
