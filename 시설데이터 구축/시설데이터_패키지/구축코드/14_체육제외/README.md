## 선택과 재현

`../시설_선택규칙.json`이 현재판의 명시적 제외 설정이다. `build_통합.py`와 `build_분석용.py`는 동일한 선택 모듈을 사용한다. `데이터/시설별/체육시설업_조건부/`는 이전 채택 증거이며 활성 빌드에서는 선택하지 않는다. 코드·원자료·캐시·보정 근거는 보존했다.

```powershell
python 구축코드/14_체육제외/release_v14.py verify
```

패키지 루트에서 실행한다. Python3.12, pandas3.0.2, pyarrow23.0.1, numpy 환경을 사용했다. `rebuild_check/`에만 재생성하며 현 배포본을 덮어쓰지 않는다. 삭제 후에는 현재130입력·선택규칙·정본 해시·오프라인 재현을 새로 검사하고, 과거 v1.3 비교는 봉인된 역사 증거와 삭제영수증으로 확인한다. 과거 파일이 없다는 이유만으로 통과시키지 않는다. 추가 HTTP·키 읽기 없음. 최종 근거는 `final_verification.json`, 파일별 교체 해시는 `promotion_manifest.json`, 시설×연도 전후집계는 `시설연도_전후비교.csv`, 코드 해시는 `build_hashes.json`이다. 최초 `stage`는 v1.3가 활성 경로에 있을 때만 가능하도록 가드되어 있다.
