## 1. 전체 흐름

```
원천 파일 (각 유형 폴더 raw/, 같은 이름 .metadata.json에 URL·다운로드 시각·SHA-256)
  → ① 원 빌드   구축코드/01_인허가/<유형>/build_*.py · 구축코드/02_명부/… · 구축코드/03_교육교통공원상가/…
                → facilities_<유형>_2020_01 / 2025_01 (.parquet·.csv), qa_<유형>.json
  → ② 신뢰도 승격 구축코드/11_신뢰도_승격/<유형>/ : 공식 통계 대조, 범위 제한(scope_flag), 좌표 보완(좌표보완_v2, _좌표보완_v3)
  → ③ 채택      데이터/시설별/<시설>/ : 활성31종의 채택본 + 제외 체육1종의 이력 보존 (원천·조건은 데이터/채택목록.csv)
  → ④ 무결성 보정 구축코드/12_무결성보정/ : 어린이집 좌표 20행, 2025 휴업 6행, 휴게음식점·미용업 결측 좌표 1,453행 (문서/무결성_검증.md)
  → ⑤ 분석용    구축코드/build_분석용.py : 선택규칙 적용31종 + 일상소매(구축코드/03_…/retail_daily) → 데이터/서울시설_2020_2025_분석용.parquet
```

## 2026-09-29 v1.4 선택 및 시점 가정

체육시설업만2020·2025에서 제외하며 다른 유형·소매·좌표값은 불변이다. 원 종료일이 기준일 뒤인 기록도 현재 취소·말소 상태로 제외했던 선택 규칙이 근거다. 관련 후보1,480/167 및 최종수정일 대체14/0은 기록 단위이며 실제 누락 시설 수나 접근성 영향으로 바꿔 말하지 않는다. 공공체육을 대신 넣지 않았다. 근거 스냅샷과 전후집계는 `구축코드/14_체육제외/근거/`와 `시설연도_전후비교.csv`에 있다.

공공시설의 명부 날짜 차이는 사용자가 채택한 인접시점 대리 가정이다. 보건소 후시점 명부·주민센터·소방 연도판 등을 정확한 과거 관측 검증으로 표현하지 않는다. 소매 역사 원배포본은 요청했으나 미입수이므로 현재 소매를 유지하고 민감도·시점 한계를 보고한다.
