# 11_신뢰도_승격 — 작업지침 (2026-09-24)

목표: 신뢰도 중·하 시설을 '상'으로 올릴 수 있는지 시설별로 시험하고, 가능한 방법을 채택한다.

## '상' 판정 기준 (세 조건 모두 충족)
- T 시점: 두 시점 모두 목표 창(2019-09~2020-05 / 2024-09~2025-05) 안의 공식 기준일 자료이거나,
  역산 결과가 **독립 공식 통계**와 서울 합계 ±5% 이내(두 시점 모두). 가능하면 구별 비교(25개 구, 상관계수·최대 편차)도 제시.
  정의 차이(업종 포함 범위, 휴업 포함 여부 등)로 차이가 나면 원인을 설명하고 정의를 맞춘 비교를 추가.
- D 정의: 두 시점 동일 정의. 범위를 좁히면(예: 이용시설만) 그 규칙을 명시하고 두 시점에 똑같이 적용.
- S 공간: 서울 내 좌표율 ≥95%, 그리고 좌표율 85% 미만인 자치구가 없음.
- T·D 충족, S 미충족 → **'상(구 단위)'**: 주소의 자치구로 구 단위 집계에만 사용.
- 그 외 → 중 / 하 유지, 이유 기록.

## 방법 (해당되는 것 모두 시도)
1 공식 통계 대조 / 2 범위 제한으로 정의 맞춤 / 3 좌표 보완(재지오코딩) 또는 구 단위 집계 + 결측 편중 검사 / 4 두 버전 민감도 비교

## 규칙
- 원본 폴더(01_인허가, 02_명부, 03_교육교통공원상가, 10_신뢰도_상)와 00_공통_데이터, SGIS 폴더는 **수정 금지**. 결과는 11_신뢰도_승격/<시설>/ 에만 쓴다.
- 파일 삭제 금지(필요 시 _to_delete/ 로 이동).
- API 키: $HOME/mnt/_secrets/facility_api.env 에서 읽기만. 값 출력·기록·로그 금지. DATA_GO_KR_KEY는 urllib.parse.unquote 후 사용.
- 지오코딩: Kakao 우선, VWorld 보조. 건물번호/번지까지 정확히 일치한 결과만 채택. coord_method에 방식 기록. 초당 10건 이하. 캐시 사용.
  좌표 채운 행은 x_5179,y_5179, inside_seoul, adm_dong_cd, oa_cd, grid100_cd를 원 빌드와 같은 방식(기존 _common/lic_common.py, 02_명부/_lib/mb.py, 03_교육교통공원상가/_lib/fac.py 참고)으로 채운다.
- robots.txt 차단 또는 WebFetch가 차단한 사이트를 curl 등으로 우회하지 않는다. file.localdata.go.kr은 WAF 차단 상태 — 사용 금지.
- device_bash 1회 최대 180초. 긴 작업은 청크 + 체크포인트로 나눠 실행.
- 공식 통계 원본 파일은 <시설>/raw/ 에 저장, 출처 URL·기준일 기록.
