# 시설별 채택 파일의 활성 선택 — facility-v1.4

활성 통합 입력은31종이다. `체육시설업_조건부/`의2020·2025 parquet/CSV는 이전 v1.3 채택의 증거로 보존하며 **v1.4 활성 입력에는 포함하지 않는다**. 두 빌드는 `../../구축코드/시설_선택규칙.json`을 공통 적용한다. 일상소매는 기존 구축코드 결과를 분석본에 직접 더하므로 최종32종이다.

폴더 전부를 임의 합치면 제외된 체육이 다시 포함될 수 있다. 공식 `build_통합.py`·`build_분석용.py` 또는 등록된 분석본을 사용한다. 원본 파일을 삭제하거나 좌표를 변경하지 않았다.
