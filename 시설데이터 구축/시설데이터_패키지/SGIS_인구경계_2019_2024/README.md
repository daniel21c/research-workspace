- 출처: 국가데이터처 SGIS 통계지리정보서비스 자료제공(자료신청, 2026-09-23~24 신청·다운로드)
- 좌표계: 모두 EPSG:5179(UTM-K, GRS80)
- 용도: 2020-01 시점 = 2019년 통계(11.1 기준), 2025-01 시점 = 2024년 통계(11.1 기준)
- 무결성: 모든 파일의 크기와 SHA-256은 `manifest_sha256.csv`에 있다. 원본 zip은 `00_원본zip/`에 보존했다.
- 이용조건: 결과물(논문 등)이 완성되면 국가데이터처에 사본 1부(또는 URL)를 제출해야 한다(자료신청 시 동의).

- 집계구 통계 코드와 집계구 경계 코드는 19,097개가 모두 일치한다. 행정구역 통계의 동 코드 426개는 2025 동 경계와 모두 일치한다.
- 2019 동 경계 코드(7자리)는 끝에 0을 붙이면 2025 코드(8자리)와 연결된다. 2019→2025 사이 서울 행정동 변동은 다음과 같다: 상일동 → 상일1·2동, 일원2동 → 개포3동, 항동 신설(424 → 426).

## 사용 시 주의

1. **100m 격자에는 연령별 인구가 없다.** 총인구·남녀만 있다(연령별은 1km 이상 격자). 연령별 수요는 집계구 성연령별 인구로 배분한다.
2. **격자 비밀보호:** 5 미만 값은 0 또는 5로 무작위 대체되고, 나머지 값에도 최대 ±7(사업체 ±4)의 노이즈가 있다(iLBA 기법, `04_참고문서` 이용안내). 셀 단위 값을 그대로 해석하지 않는다.
3. **집계구 비밀보호:** 작은 값은 N/A로 제외된다. 성연령별 인구 행의 약 15~17%가 N/A이고, 연령 합계는 총인구의 약 99%다.
4. **사업체 수 비교 주의:** 서울 격자 사업체 합계가 2019년 742,974개에서 2024년 1,082,261개로 +46%다. 조사 방식 변화 가능성이 있으므로 두 해를 그대로 비교하지 않고 연도별 검증용으로만 쓴다.
5. 2025 시점의 동 경계는 2024년 말이 아니라 2025년 6월 30일 판이다.
