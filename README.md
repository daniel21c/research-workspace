## 작업 규칙

공통 접근성은 `access-engine-v3.3-facility-v1.4-20260929`의 정의·설정·입력 지문을 함께 따른다. 연구2/JTG 주분석은 경계·OD에 의존하며 시설 접근성 재계산을 요구하지 않는다. 연구3/AG는 현행 경계 재배정·서비스 포착 설계에 7범주를 적용하고, 연구4/KPA는 경계동 진단을 주분석으로 두며 시설·접근성을 보조 비교에 사용한다. 연구1의 공공시설 7유형은 공통 기능 7범주와 다른 집합이다. 공통 지표 문서에 남은 과거 회귀 사용처를 현 연구질문으로 자동 적용하지 않는다. 세부 의존성과 검증 단계는 위 실행기준을 따른다.

1. **자기 폴더만 고친다.** 다른 폴더와 `00_공통_코어엔진/`은 읽기만 한다. **이 폴더 밖의 경로를 코드에 쓰지 않는다**(원자료가 필요하면 사본을 안에 두고 배포목록에 적는다). 설계 기준 문서를 바꿔야 하면 자기 폴더의 `작업기록.md`에 제안으로 남기고, 허브에서 반영한다.
2. **각 폴더의 `작업기록.md`**에 작업이 끝날 때마다 날짜, 한 일, 결정, 남은 일, 다음 단계를 추가한다. 다른 대화는 이 기록으로 상황을 파악한다.
3. **데이터는 Git에 넣지 않는다.** 원자료·경계·시설·결과 파일·PDF는 제외한다. 필요한 데이터는 `데이터_배포목록.md`에 등록된 배포본만 쓴다.
4. **숫자는 코드에서 나온다.** 표·문서에 계산하지 않은 값을 결과처럼 쓰지 않는다. 예시값은 "예시"라고 표시한다.
5. **논문·발표 본문에 작업 메모를 쓰지 않는다.** (PASS, BLOCKED, 검증 필요 등)
6. **원자료와 다른 작업자의 파일을 지우거나 덮어쓰지 않는다.** 정리가 필요하면 이 폴더 밖 보관 위치(`D:\Research\_archive\`, 공유본 아님)로 옮긴다.

## Git 규칙

- 브랜치: 설계 단계에는 `main` 하나를 쓴다. 폴더별 담당으로 충돌을 막는다. 분석 코드 단계에 들어가면 파트별 브랜치·작업폴더 도입을 다시 검토한다.
- 누가: **이 PC에서 직접 실행되는 모든 대화(Windows의 Claude Code, Codex, 사용자)는 자기 폴더를 직접 커밋·푸시한다.** 다른 대화의 작업은 `git pull`로 받아 읽는다(`git log --oneline -- <폴더>`로 확인). 폴더를 원격으로 연결해 쓰는 세션(Cowork 등)은 잠금 파일(`.git/index.lock`)이 남을 수 있어 조회만 한다(`GIT_OPTIONAL_LOCKS=0 git -c safe.directory='*' status`).
- 메시지: `[폴더명] 요약` 형식이다. 예: `[01_생활권_필요성] 모의실험 설계 초안`. 두 폴더를 함께 올리면 커밋을 폴더별로 나눈다.
- 커밋 절차(Git Bash 기준, `G="git -c safe.directory=*"`):
  1. `ls .git/index.lock` — 있으면 다른 Git 작업이 도는 중이다. **지우지 말고** 기다리거나 사용자에게 알린다.
  2. `$G fetch origin` 후 `$G status -sb` — 뒤처졌으면 `$G pull --ff-only`. 실패하면 멈추고 사용자에게 알린다.
  3. `$G add -- <자기 경로들>` → `$G diff --cached --name-only`로 **자기 폴더 밖 파일이 없는지** 확인 → `$G commit -m "..." -- <같은 경로들>`. 경로를 지정한 커밋이라 다른 대화가 스테이징한 것은 섞이지 않는다.
  4. `$G push origin main` — 거부되면 `$G pull --no-rebase --no-edit`(병합 커밋) 후 다시 푸시한다. 병합이 다른 폴더의 미커밋 변경과 겹쳐 거부되면 멈추고 사용자에게 알린다.
- 하지 않는 것: `git add .`·`git add -A`, 다른 폴더 스테이징·커밋, `stash`·`reset --hard`·`checkout -- <파일>`·`restore`·`clean`(다른 대화의 미커밋 작업을 지운다), 강제 푸시, 푸시한 커밋의 `rebase`·`amend`, `--no-verify`, `.git/index.lock` 삭제.
- 원격: `https://github.com/daniel21c/research-workspace.git` (`main`).
