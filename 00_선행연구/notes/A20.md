# A20 Hooghe (2003) 다층 거버넌스의 두 유형

- 서지(확인 상태): Hooghe, L., & Marks, G. (2003, March). *Unraveling the Central State, But How? Types of Multi-Level Governance*. Reihe Politikwissenschaft / Political Science Series 87. Wien: Institut für Höhere Studien (IHS), Institute for Advanced Studies, Vienna. 저자명은 알파벳 순. 동명 논문의 학술지 게재본(감사의 글에 APSR 편집자·심사자가 언급됨) 서지 정보는 미확인. 쪽수는 워킹페이퍼 본문 쪽수. (L: 로컬 PDF 확인, 2026-09-24)
- 연구 질문: 중앙국가에서 권한이 위·아래·옆으로 분산될 때, 다층 거버넌스는 어떻게 조직되어야 하는가. 관할(jurisdiction) 설계의 기본 대안은 무엇인가.
- 자료·단위·기간: 이론적 종합. EU 연구·국제관계·연방주의·지방정부·공공정책 문헌(Table 1, p. 3)과 예시 통계(미국 특별구, 스위스 기능연합, EU NUTS 인구 중위값 등).
- 방법(식·알고리즘·파라미터): 문헌 종합에 의한 유형화. Table 2(p. 7): Type I(일반목적, 비교차 멤버십, 제한된 층위 수, 체계 전반 구조) vs Type II(과업특정, 교차 멤버십, 층위 수 무제한, 유연한 설계). 수식 없음.
- 주요 결과(원문 쪽수와 함께):
  - 거버넌스를 "공적 영역의 구속력 있는 의사결정"으로 정의하고, 미국 지방정부의 통합론(consolidationists) 대 분절론(fragmentationists) 논쟁에서 출발 (p. 1).
  - 대규모 관할은 규모의 경제·외부효과 내부화·효율적 재분배에 유리하나, 이질적 인구·생태에 단일 정책을 부과할 때 불리; 다층 거버넌스는 이질성에 맞춰 규모를 조정 가능 (pp. 5–6).
  - 규모의 경제는 자본집약적 공공재에서 크고 교육 같은 노동집약 서비스에서 작음 (p. 6).
  - Type I은 러시아 인형처럼 중첩되며, 각 영역 규모에 관할이 하나뿐이고 수십 년 이상 안정적; 관할 개편은 비용이 크고 드묾 (pp. 7–9).
  - Type II는 기능별로 분화되고 수요 변화에 따라 생겼다 사라짐; 미국 특별구 수는 1952년 12,340개에서 2002년 35,356개로 증가 (pp. 8, 10).
  - Type II는 대개 Type I 위에 덧씌워진 조각보(patchwork) 형태로 존재 (p. 12).
  - 조정 딜레마: 관할 수가 늘수록 2차 조정비용이 급증(Scharpf의 법칙); Type I은 관할 수를 제한하고, Type II는 과업을 분리해 상호작용을 줄여 대응 (pp. 13–15).
  - EU NUTS 중위 인구: NUTS 1 389만, NUTS 2 142만, NUTS 3 36.9만, NUTS 4 4.8만, NUTS 5 5,100명 (p. 14).
  - Type I은 포괄적 공동체에 기반하며 발언(voice) 지향, Type II는 외재적 기능 공동체이며 이탈(exit) 지향 (pp. 15–16).
- 한계: 워킹페이퍼판. 두 유형의 공존 방식, 동태적 특성, 민주주의에 미치는 영향은 열린 질문으로 남김(p. 17). 경험적 검증 없음.
- 이 논문의 어느 절, 어떤 주장에 쓰는가: 2.1 필요성(거버넌스·협의) — 행정동·구 같은 Type I 관할 사이에 생활권을 과업특정·유연한 Type II형 계획 단위로 둘 수 있다는 개념 틀. 서비스별 최적 규모가 다르다는 논거(p. 6)로 중간 단위 필요성 뒷받침. 2.4 시간 변화 — Type I 경계는 경직적이고, Type II는 수요 변화에 따라 조정된다는 대비를 생활권 개정 주기 논의에 사용.
- 인용할 문장(쪽수): "Type I jurisdictions choose citizens, while citizens choose Type II jurisdictions." (p. 17)
- 반대 증거·주의: 생활권은 법적 권한·조세권이 없는 계획 단위이므로 Type II "관할"과 동일시하면 과대해석. 조정비용 논리는 생활권 수를 늘릴수록 협의 비용이 커진다는 반론으로도 쓰일 수 있음. 최종 인용은 학술지 게재본 쪽수와 대조 필요.
