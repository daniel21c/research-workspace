# B60 Peel (2017) 메타데이터는 ground truth가 아니다

- 서지(확인 상태): Peel, L., Larremore, D. B. & Clauset, A. The ground truth about metadata and community detection in networks. arXiv:1608.05878v2 [cs.SI], 3 May 2017 (L: 로컬 PDF 확인, 2026-09-24). 학술지판 *Science Advances* 3(5) e1602548은 로컬 PDF에 표기되지 않아 미확인. 쪽수는 arXiv판 기준.
- 연구 질문: 관측된 노드 속성(메타데이터)을 공동체 탐지의 "정답(ground truth)"으로 취급하는 관행은 타당한가? 메타데이터와 네트워크 구조의 관계를 어떻게 검정할 수 있는가?
- 자료·단위·기간: Zachary 가라테 클럽, Lazega 법률회사 네트워크(3개 망, 5개 속성), 말라리아 var 유전자 네트워크 9개, 합성망.
- 방법(식·알고리즘·파라미터): 공동체 탐지를 역문제 G = g(T), C = f(G)로 정식화하고 f* = argmin_f d(T, f(G))로 둔다 (식 1). 메타데이터 M을 목표로 삼으면 f* = argmin_f d(M, f(G))가 된다 (식 3). BESTest는 메타데이터 분할에서 SBM 엔트로피 H(G;M)를 구해 무작위 치환 π̃와 비교한다. p-value = Pr[H(G;π̃) ≤ H(G;M)] (식 4). neoSBM은 메타데이터에 고정된 노드와 자유 노드를 두고, 로그우도 L = L_SBM + qψ(θ)로 메타데이터 분할과 최적 분할 사이의 경로를 탐색한다.
- 주요 결과(원문 쪽수와 함께):
  - 탐지 결과가 메타데이터와 불일치하는 원인은 넷 중 하나이며 서로 구별할 수 없다: (i) 메타데이터가 구조와 무관 (ii) 서로 다른 측면을 포착 (iii) 망에 공동체가 없음 (iv) 알고리즘 실패 (p. 2).
  - 정리 1: 고정된 G에 대해 ground truth 탐지 문제의 해는 유일하지 않다 (p. 3).
  - 가라테 클럽의 SBM 우도 지형에는 두 봉우리가 있다. 파벌 메타데이터 분할은 낮은 봉우리이고, 더 높은 봉우리는 리더–추종자 분할이다 (p. 2, Fig. 1).
  - 어떤 메타데이터를 기준으로 삼느냐에 따라 SBM과 DC-SBM 중 '더 나은 모형'이라는 결론이 뒤바뀔 수 있다 (p. 4).
  - 정리 3(No Free Lunch): 가능한 모든 문제에 대해 평균한 정확도(AMI)는 방법과 무관한 상수이다. 따라서 메타데이터를 알고리즘 비교 벤치마크로 쓰지 말아야 한다 (p. 4).
  - 낮은 p-value는 통계적 유의성일 뿐 효과 크기가 아니다 (p. 5). Lazega에서는 여러 속성이 동시에 유의해 어느 하나도 ground truth로 볼 수 없다 (p. 6). 말라리아망에서는 유전체 기원 메타데이터가 9개 망 모두에서 유의하지 않았다 (p. 6, Table II).
  - neoSBM 경로에서 우도가 정체(plateau)했다가 급변하면, 메타데이터와 최적 분할이 구조의 서로 다른 측면을 포착한다는 뜻으로 해석한다 (p. 6).
- 한계: (iii) 공동체 구조가 없는 경우는 다른 연구에 맡겼다 (p. 7). 이론과 검정은 SBM 계열을 중심으로 전개되고, 사례는 소규모 사회·생물망이다. 공간 네트워크나 가중 OD망은 다루지 않는다.
- 이 논문의 어느 절, 어떤 주장에 쓰는가: 2.2.5 "공식 생활권을 ground truth로 쓰지 않는다"의 핵심 근거이다. 2030 서울 생활권계획의 권역은 메타데이터 M에 해당하므로, 탐지 결과와 불일치해도 알고리즘 실패로 해석하지 않는다. 비교 지표(NMI/ARI)는 성능이 아니라 두 구획의 관계를 기술하는 값으로 쓰고, 순열 기반 검정(BESTest 유형)을 도입할 근거로도 쓴다.
- 인용할 문장(쪽수): "labeling any particular set to be 'ground truth' is an arbitrary and generally unjustified decision" (p. 7)
- 반대 증거·주의: 저자들은 메타데이터가 여전히 가치가 있고 구조와의 관계 탐색에서 통찰을 줄 수 있다고 강조한다 (p. 4, p. 7). 따라서 공식 생활권과의 비교를 무의미하다고 주장하면 과잉 해석이 된다. 쪽수를 학술지판으로 인용할 때는 다시 확인해야 한다.
