## Data availability

This study uses only publicly accessible datasets obtained from third-party providers: grid population from Statistics Korea's Statistical Geographic Information Service (SGIS); facility records from LOCALDATA (Ministry of the Interior and Safety), the Ministry of Culture, Sports and Tourism and the Seoul Open Data Plaza; living-zone boundaries, the living-zone plan park layer and the Seoul Living Mobility Dataset from the Seoul Open Data Plaza; and the street network from OpenStreetMap. All data are available from the original sources. The analysis code is available from the corresponding author on reasonable request.
