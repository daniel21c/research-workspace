# GPT Pro 프롬프트 수정 제안 — 생활권 필요성의 실증 검증

검토 대상: `결과총람_20261002.md`, `GPTPro_스토리설계_프롬프트_20261002.md`.
아래는 연구1의 스토리 설계용 후보 프롬프트다. 학위논문 전체의 제목·RQ·장 구성을 확정하거나 저장소 문서를 변경하는 지시가 아니다.

---

너는 도시계획·접근성·입지 최적화 분야의 논문 설계자다. 첨부 결과총람의 A1~A14와 B1~B10, 총 24개 분석항목만을 사용하여 연구1의 논지를 설계하라. 독립적인 실험 24회나 외부 재현 24건으로 표현하지 마라.

## 1. 고정할 것은 연구 질문이며, 긍정 결론이 아니다

주제는 **생활권이라는 중간 계획단위의 필요성에 대한 실증 검증**이다. 이를 유용성·활용 가능성이라는 다른 주제로 바꾸지 마라.

교수님의 질문은 “접근성은 100m 격자로 재고 시설도 격자에 놓을 수 있는데, 왜 생활권이라는 중간단위가 필요한가?”이다.

그러나 “생활권이 반드시 필요하다는 결론”을 전제로 두지 마라. 필요성이 지지됨 / 조건부·부분적으로 지지됨 / 비교한 조건에서 지지되지 않음 / 현 자료로 판정 불가를 모두 허용한다. 모든 정의가 부분 지지 또는 미지지라면, 그중 가장 나은 것을 선택하더라도 입증 완료로 승격하지 마라.

이번 정의 선택은 결과를 본 뒤 이루어지는 탐색적 작업이다. 사전에 고정된 가설을 검증한 것처럼 서술하지 마라.

## 2. 자료와 작업의 범위

새 실험, 최적화, 시뮬레이션, 설문, 문헌조사 제안으로 답을 미루지 마라. 기존 결과의 재배열, 명시된 숫자의 단순 대조, 정의와 분모의 확인만 사용한다.

총람의 숫자는 제공된 요약값이며 이번 답변에서 독립 재현한 값이 아니다. ‘강함’은 생활권 필요성의 입증 등급이 아니다. 계산·산출의 확인 수준과 주장에 대한 직접성을 구별한다.

총람에 모순·정의 누락·근거 경로 누락이 있으면 그 점을 표시하고, 해당 명제만 보류하라. 빈칸을 상식이나 외부 지식으로 메우지 마라. 전체 작업을 중단하거나 새 분석을 요구하지 마라.

## 3. 반사실과 필요성 정의

정의 후보를 최소 세 개 작성하라. 후보마다 다음을 고정한다.

- 목표: 전체 도달·묶음 완결·하위집단 성과·권역별 최소기준 중 무엇인가.
- 필요성의 대상: 생활권이라는 제도, 116개 공식경계, 중간 공간규모, 추가적인 지역별 평가기준 중 무엇인가. 중간에 대상을 바꾸지 마라.
- 비교 대안: 격자 기반 계산, 격자 기반 특정 배치 규칙, 동별 하한, 구별 하한, 생활권별 하한, 무작위 구획 중 무엇인가.
- 반사실: 생활권을 제거한 대안이 같은 목표·평가기준·추가량 상한에서 실제로 무엇을 충족하지 못했는가.
- 비교 공통조건: 인구·시설·시간기준·후보 입지·추가량 상한·평가분모가 같은지, 다르면 무엇이 다른지.
- 결론의 강도: 실현 불가능, 저장된 해에서 미달, 자동으로 보장하지 않음, 단지 비교안보다 낮음, 미검정 중 무엇인가.

특히 다음을 구별하라.

1. 격자를 계산 단위로 쓰는 것과 총량만을 최적화하는 것은 다르다. 생활권 하한을 둔 배치도 격자에서 계산할 수 있다.
2. 지역별 목표를 별도로 정할 필요성과, 공식 생활권이라는 중간단위가 불가결하다는 명제는 다르다.
3. 공식 생활권에서 평가했을 때 결손이 발견됐다는 사실은 그 평가경계가 유일하게 필요한 경계임을 뜻하지 않는다.
4. ‘동의 K_min이 상한을 초과함 / 구의 하한이 약함 / 생활권의 하한이 가능함’은 설정된 하한들의 조건부 비교다. 세 대안이 완전히 동일한 공간적 목표를 수행한다고 가정하지 마라.
5. 무작위 116개 구획 대비 결과는 그 귀무 설계에 대한 비교이지 모든 비생활권 대안을 배제하는 검정이 아니다.

## 4. 결과를 연결할 때의 제한

- A계열 단일 시설 결과와 B계열 6분야 AND 묶음 결과를 구분한다. 하위20 집단과 하한의 정의도 같다고 가정하지 않는다.
- A10의 PG 대 PL 비교와 PL 대 무작위 비교는 비교군·평가지표가 다르다. 이를 자동으로 ‘PG는 지역 결손을 해결 못함, HY만 해결함’이라는 결론으로 합치지 않는다. HY의 ‘대부분’은 정확한 결과가 제시된 범위에서만 사용한다.
- B2·B6는 저장된 최적해의 분포다. ‘총량 목표가 지역·하위집단 성과를 보장하지 않는다’와 ‘모든 총량 최적해가 반드시 같은 분포를 만든다’를 구별한다.
- B5의 600·720·900초는 2025년 정확해 비교에서 상대차이와 절대차이를 모두 적는다. 상대차이는 약 47→28→8%, 절대차이는 약 7.7→8.2→4.3%p다.
- B9의 경계·목적·하한 차이를 독립적인 효과 분해로 합산하거나 순위화하지 않는다. 같은 비교 조건끼리 읽는다.
- 평균 도달범주 수 하한을 묶음 완결률 하한 또는 개인의 최소보장으로 바꾸지 않는다.
- 순환적인 크기 순서는 필요성 근거로 쓰지 않는다. 주어진 시설·하한·상한에서의 수치적 임계점은 조건부 결과로 사용할 수 있다.
- 116이 보장 가능 창 안에 든 4/7뿐 아니라 밖의 3/7도 함께 쓴다.
- ‘강함’인 반증 결과와 불리한 조건도 본문에서 숨기지 않는다. 같은 원자료·해의 재집계를 독립된 증거로 세지 않는다.
- 시설 공급에 대한 잠재적 보행 도달을 실제 이용·개인별 필요 충족·제도적 책임의 효과로 해석하지 않는다.
- 공식 계획경계와 이동 비교경계를 구분한다. 이동경계의 일반적 우월성이나 공식경계 대체를 결론으로 쓰지 않는다.

## 5. 시작 전에 처리할 총람의 내부 확인사항

다음은 새 실험 요청이 아니라 현재 문서의 내부 대조사항이다.

1. B9의 ‘S1 < IND < S2 < S3’는 숫자와 다르다. 본문 값은 S1 < S2 < IND < S3의 순서다. 비교방법을 명시한다.
2. B2의 ‘구는 모두 0% 아님’과 ‘최저 5.9%·0%’는 정밀도 설명 없이 양립하지 않는다. 반올림 여부·원 분자를 확인할 수 없으면 ‘구에 0% 권역이 없다’는 근거를 보류한다.
3. B2는 ‘이 문서 계산’으로만 인계되어 있다. 기존 집계표·입지 해·정확한 분모의 경로가 제시되지 않으면 원자료 검증 완료로 쓰지 않는다.
4. A3·A12의 통제는 먼저 ‘권역 수 116 고정’으로 명명한다. 면적·인구·형상까지 통제했다고 쓰지 않는다.
5. A13의 시설 섞기 결과로 공식경계가 역사적으로 시설과 무관하게 만들어졌다고 추론하지 않는다.
6. B10의 지역아동센터 ‘제외’가 공급층 제거인지 필수 범주 삭제인지 정의가 없으면 수준 하락의 메커니즘을 확정하지 않는다.

## 6. 요구 출력

### 1) 현재 상태
확정 가능한 것 / 조건부 후보 / 판정 불가를 먼저 분리한다. 필요성 주제는 유지하되 결론은 증거에 맞춘다.

### 2) 필요성 정의 후보 표
정의 | 필요성의 정확한 대상 | 목표와 공통 평가기준 | 생활권 없는 반사실 | 직접 근거 | 반대 결과·남은 연결 | 판정(받침/부분/못 받침 또는 판정 불가).

### 3) 선택한 스토리
Q1~Q3 각각 [질문 / 답 / 근거 A·B 번호와 핵심 수치 / 모집단·분모·시점 / 가정 / 허용 문장 / 금지 문장 / 심사 반론과 답]을 작성한다.

앞 Q의 결과가 다음 질문을 여는 연결은 명시하되, 앞 Q가 다음 Q의 결론을 이미 증명한 것처럼 쓰지 않는다. 결론 한 문단에는 필요성의 지지·미지지·미판정 범위를 모두 적는다. 긍정 결론을 반드시 포함할 필요는 없다.

### 4) 대안 스토리와 비교
다른 정의 또는 다른 Q 배열을 하나 작성한다. 자료에 대한 충실성·교수님 질문과의 직접성·주장 범위 면에서 비교한다. ‘강한 문장이 나오는가’만으로 선택하지 않는다.

### 5) 결과의 배치
A1~A14·B1~B10 전부를 핵심 / 보조 / 부록 / 본문 서사 제외로 분류하고 이유를 적는다. 본문 제외는 원자료·결과 기록의 삭제가 아니다. 핵심 주장에 반하는 결과는 관련 본문이나 한계에 남긴다.

### 6) 제목 후보 세 개
국문·영문을 제시한다. 필요성/necessity를 포함하되, 입증 여부를 제목에서 선취하지 않는다. 연구1 후보 제목이며 학위논문 전체 제목을 확정하지 않는다.

### 7) 남는 약점 세 개
문장·구성으로 해결 가능 / 기존 기록 대조 필요 / 현 자료로 판정 불가로 나눈다. 부족한 점은 명확히 쓰되 구체적인 새 실험 제안으로 답을 마무리하지 않는다.
