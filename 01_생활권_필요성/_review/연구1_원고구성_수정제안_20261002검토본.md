# 연구1 저널 원고 구성 수정 제안

검토 의견에 따른 **후보안**이다. 기존 연구설계·원고 구성 파일을 덮어쓰지 않았으며, 박사학위논문 전체의 제목·장·RQ를 확정하지 않는다.

## 논문의 중심 문장

동일한 보행시간과 유형별 추가량 상한 아래 서비스 묶음의 완결을 평가하고, 완결률 최적화·유형별 독립 최적화·권역별 하한 및 배분 절차의 결과를 구분한다. 공식 계획경계는 공동 집계·점검 지리로 검토하되, 이 분석만으로 중간단위의 필수성이나 완결 보장 역할을 증명하지 않는다.

## 질문과 허용 답

| 질문 | 수정 질문 | 허용 답 |
|---|---|---|
| Q1 | 같은 시간기준에서 묶음별 완결과 결손 구조는 어떻게 다른가? | 600초·900초에서 각각 비교. 범주·시설층·대리 정의 조건부 기술 결과 |
| Q2 | 같은 유형별 추가량 상한에서 완결률 직접 최적화와 유형별 독립 최적화는 어떤 차이를 보이는가? | joint MIP 대 저장된 IND 최적 입지 조합의 차이. 탐욕·하위20·민감도는 별도 구분 |
| Q3 | 선정한 경계·하한·배분 절차의 전체/하위20 성과는 어떻게 다르며 무엇을 분리해 해석할 수 없는가? | 절차별 차이와 상충관계. 경계 중립·약속 내용만의 효과·제도적 필요성은 미확정 |

## 동일한 Q 순서를 유지하는 목차

| 절 | 제목·내용 |
|---|---|
| 1 서론 | 서비스 도달 측정, 입지 선택, 공동 집계·점검 지리가 왜 다른 문제인지 제시. 중간단위 필요성을 결론으로 선취하지 않음 |
| 2.1 공통 문헌 | 측정·입지·계획 지리, 집계와 경계 문제 |
| 2.2 Q1 문헌 | 묶음 완결, 충분성 취지와 계산식 구별, 시간 문턱의 근거 |
| 2.3 Q2 문헌 | 유형별·묶음 목적의 차이, 입지 최적화와 분배 지표 |
| 2.4 Q3 문헌 | 하한·배분·계획/점검 단위. 제도적 해석은 실증과 구별 |
| 2.5 기여 | 아래 세 수행 기여. ‘최초·선행연구 없음’은 문헌 대조 완료 전 사용하지 않음 |
| 3.1 공통 자료 | 표본·분모·기준시점, 시설층 증거등급, 100m 격자·보행망, 후보·K·경계 |
| 3.2 Q1 방법 | 동일 시간기준 완결곡선, 결손 분포, 동률 포함 집단과 분수 가중 하위20 |
| 3.3 Q2 방법 | IND exact/joint MIP/탐욕 분리, 예산은 상한, 독립 입지 재평가, 민감도. 공동입지를 유지하면 귀무·대응법도 여기 |
| 3.4 Q3 방법 | 평균 범주 수 FLOOR·ZONE·경계 시나리오, 공통 참조τ, 식별할 수 있는 차이와 남는 교란 |
| 4.1 공통 기술 통계 | 분석 인구·후보 수·유형별 K·실제 선택량·실행/검증 상태. Q1의 완결곡선을 여기서 선공개하지 않음 |
| 4.2 Q1 결과 | 같은 T에서 묶음별 완결·결손. 600초와900초 패널 구별 |
| 4.3 Q2 결과 | 정확해 대 정확해, 탐욕 대 탐욕, 형평 지표를 구분. 공동입지 결과는 말미 보조 또는 부록 |
| 4.4 Q3 결과 | 하한 구속성→전체/하위20 교환→경계 비교의 조건·한계. 0 결과로 통합하지 않음 |
| 5.1 Q1 논의 | 측정 정의·문턱·대리 자료에 따른 범위 |
| 5.2 Q2 논의 | 완결 목적의 차이 규모, 다른 지표와의 교환, 탐욕의 한계 |
| 5.3 Q3 논의 | 공식 계획경계의 공동 집계·점검 활용 가능성. 중간단위 필요성은 별도 제도적 과제 |
| 5.4 한계·결론 | 역사 패널 아님, 비용·수용력·이용자격 미반영, 조건부 전이, 잔여 비교 교란, 명확한 허용 결론 |

공동입지 검정이 본문 논지를 과도하게 넓히면 방법·결과를 함께 부록으로 이동한다. 개별 시설 PG, 경계 제한 손실·시설 섞기 역시 새 AND 묶음 결과와 추정대상이 달라 별도 보조 분석으로 표시한다. 부록으로 옮겨도 결과를 숨기거나 삭제하는 것이 아니라 역할을 구분하는 것이다.

## 기여 문장 후보

1. 일상 기능과 계획 대상 서비스 묶음을 같은 시간기준으로 비교하여 완결·결손 구조의 차이를 제시한다.
2. 유형별 추가량 상한 아래 완결률 최적값과 유형별 독립 최적 입지 조합의 차이를 정량화하고, 탐욕 배치 성과와 구분한다.
3. 권역별 하한·배분 및 권역 수를 맞춘 경계 시나리오를 비교하여 전체 완결률과 배치 전 하위20 성과의 교환관계 및 경계 해석의 한계를 진단한다.

## 원고의 수치 제시 원칙

- 정확해 전체 성과: 2020·600초 22.8018% 대14.6815%, 2025·600초24.2196% 대16.5142%, 2025·900초59.9484% 대55.6060%.
- 탐욕 하위20: 2020 0.4257%→3.2805%,2025 0.7085%→4.9140%. 위 정확해의 형평 결과가 아님.
- 동률 가중치 α: 제출 기준 분포와 코드 공식상0.029395·0.093851. 코드에서 직접 출력해 재확인.
- 600·900초 정확해는2025 안에서 비교.720초 탐욕을 중간점으로 넣어 단조 감소 곡선처럼 연결하지 않음.
- FLOOR는 평균 범주 수 하한. 미달1·2개와 하한 단계4·8개를 비용 수치와 함께 제시.
- ‘경계 효과0’ 대신 실제 차이와 무작위/공식 경계의 잔여 차이를 보고.

## 제외·보류할 근거

05 문서분석51%는 코퍼스·분모·코딩·검증 인계 전 본문 결과로 사용하지 않는다. 기존JTG와의 신규 기여는 자료·방법·결과·표·그림·문장별 중복표로 확인한다. 세계도시 사례는 제도·운영 권한의 원문 근거와 당시 시점을 확보한 경우에만 연결한다.
