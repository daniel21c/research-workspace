# 연구1 — 격자는 사람을 채우지만 지역을 채우지 못한다: 서울 보행 생활서비스로 본 생활권의 필요성 실증 (Cities 확정본)

- 논문 위치: 박사논문 4장 1절 (Cities 투고). 영문 제목: *Grids fill people, not places: Testing the necessity of living zones for walkable public services in Seoul*. 질문: "접근성은 격자로 재고 시설도 격자에 놓으면 되는데 왜 생활권인가"(9/21 논문지도). 시작 프롬프트: [_prompts/01_생활권_필요성.md](../_prompts/01_생활권_필요성.md), 기준 문서: [박사논문_연구설계.md](../박사논문_연구설계.md)

- **답(한 줄)**: 격자로는 사람을 채울 수 있지만 지역을 채울 수는 없다. 어떤 격자 규칙도 0명 생활권을 13~21개(약 100만 명) 남기고, 생활권 최저선만 그런 생활권을 모두 채울 수 있다(시설 7종 중 6종 0개; 6분야 묶음은 같은 시설로 116개 생활권 전부를 1%·5% 최저선 위로 올릴 수 있음을 정수계획으로 증명, 비용은 5% 최저선에서 서울 전체 완결률 1.3%p 이상, 2025년 1% 최저선은 0.6%p 이상). 자치구 최저선은 거의 바꾸지 못하고 행정동 최저선은 늘어난 시설로 채우지 못했다(도서관은 불가능 증명). 공식 생활권 경계는 같은 수의 무작위 구획보다 걸어서 쓰는 시설을 덜 자른다(시설 4종 p ≤ 0.04). 보행 문턱 15분에서는 격자와의 차이가 작아진다(한계).
