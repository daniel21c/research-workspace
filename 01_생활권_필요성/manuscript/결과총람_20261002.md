- 모든 수치는 `results/` 표의 값이며 2020·2025 두 시점(인구 2019·2024)이다. 외부 검토 1~3차(`검수기록/`)가 살아남았다고 인정한 결과와, 검토가 제한을 단 결과를 구분해 적었다.
- 판정 열(결과의 확인 수준): **강함** = 두 해·여러 시설·귀무 비교에서 반복 / **조건부** = 특정 조건·정의에서만 / **기술** = 서술만 / **순환** = 정의상 나오는 순서 / **폐기** = 검토로 무효. 이 판정은 산출의 신뢰도이며, 그 결과가 "생활권 필요성"을 얼마나 받치는지는 `연구설계.md`(4판)에서 따로 판단한다.
- 24개는 독립 실험 24건이 아니라 분석항목이다. B2·B6은 같은 저장 해의 다른 집계다.
- 용어: 완결 = 정한 보행 시간 안에 묶음의 모든 범주 시설에 닿음. 공식 생활권 = 서울 2030 생활권계획 지역생활권 116. Leiden = 이동 커뮤니티 116. IND = 시설별 독립 배치, COL = 묶음 조정 배치(볼록 목적 탐욕), 정수계획 = 완결 인구 직접 최대화(갭 0).
