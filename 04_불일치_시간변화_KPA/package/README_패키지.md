# 국토계획(KPA) 투고 — 확정본 공동연구자 패키지 (20260930)

**논문**: 서울시 생활권의 자족성 상승과 경계 불일치의 지속 — 무작위 비교경계와 빅데이터 기반 가상경계를 이용한 경계 동 진단(2020·2025)
이 폴더만으로 원고의 모든 표·그림·수치를 다시 만들 수 있다(저장소 경로 불필요, `scripts/config.py`가 패키지 모드를 자동 인식).

## 0. 한 문단 요지
2020년에서 2025년 사이 서울 공식 생활권의 자족성(IFR)은 모든 자치구에서 올랐다. 그러나 무작위로 그은 경계도 같은 범위로 올랐고, 상승분의 98%는 통행 구성의 변화가 아니라 각 유형의 통행이 생활권 안에 머무는 비율이 높아진 결과였으며(거리 단축을 확인한 것은 아님) 상승 폭은 주말에 더 컸다.
같은 기간 공식 생활권과 빅데이터 기반 가상경계의 판정 불일치 D는 8.5%에서 8.3%로 소폭 낮아졌으나 자치구별 변화 방향은 일관되지 않았고(부호검정 비유의), 자족성 격차 G는 0.67%p에서 1.50%p로 벌어졌으며 그 절반가량(53%)이 통행 변화에서 왔다.
권역 크기를 맞춘 무작위 비교경계보다 공식 생활권의 IFR은 대체로 높고(구별 백분위 중앙값 97), 통행 지표상 재검토 후보는 일부 경계 동에 한정되며 두 해에 같은 재배정이 반복된다(48개 동). 별도의 순차 재배정에서 일부 경계 동의 소속만 바꾸면(2025년 65개 동) 서울 IFR이 37.9→39.6%로 가상경계(39.4%)와 비슷해지고 D는 8.3→3.2%로 준다.
결론: 자족성의 상승을 생활권 불일치의 해소로 해석해서는 안 되며, 재정비는 지목된 경계 동의 검토에서 출발할 수 있다.

## 1. 용어
- **IFR(내부통행비율, 자족성)**: 동에서 출발한 서울 내부 통행 중 같은 권역 안에서 끝나는 통행의 비율(동 내부통행 포함, 구를 넘는 통행은 외부).
- **빅데이터 기반 가상경계**: 같은 해 생활이동 통행으로 도출한 경계(자치구 내 Leiden 3,000회 합의, 개수 = 공식 생활권). 공식 생활권을 대체하는 안이 아니라 비교 기준.
- **무작위 비교경계**: 이동 정보 없이 인접한 동을 무작위로 묶은 경계. 자치구마다 1,000번 추출(중복 허용). N0 권역 수만 / N1 권역별 동 수 동일 / N2 N1 중 통행량 비중이 비슷한 것. 바닥 기준선.
- **판정 불일치 D**: 두 경계가 권역 안/밖을 다르게 판정한 통행의 비율. **자족성 격차 G** = 가상경계 IFR − 공식 생활권 IFR.

## 3. 재현 순서
이 패키지가 재현하는 범위는 집계 OD와 확정 경계(공식·가상) 이후의 계산이다. 원자료 CSV 집계와 가상경계 도출(자치구 내 Leiden 3,000회 합의)은 별도 저장소 `00_공통_코어엔진`에 있으며 이 ZIP만으로는 재현되지 않는다.
```
pip install -r scripts/requirements.txt
cd scripts
python tests/test_examples.py      # 지표 손계산 예제
python tests/test_benchmark.py     # 무작위 비교경계·재배정·백분위 함수
python k01_compute.py              # IFR·G·D·무작위 비교경계(N0) ΔIFR·G 분해     → results/
python k13_benchmark.py            # 무작위 비교경계 N0·N1·N2 대비 평가(구·생활권·동)   ~30분
python k14_reassign.py             # 한 동씩 옮기기·순차 재배정·고정경계 평가·대안 분모
python k25_change_story.py         # 자족성 상승의 유형 분해·주말 비교, D·G 변화 검정과 G 분해
python k18_v2_results.py           # 재배정 분할 검증 + 표·그림
python k19_kpa_v2.py               # 원고 docx + 원고 본문 수치 대조(k24)·변조 시험·구조 점검
python tests/test_text_claims.py   # 원고 숫자를 바꾸면 반드시 실패하는지
python k11_independent_check.py    # a·b·T 독립 재계산 + docx/hwp 표 셀 대조
python k22_hwp_kpa.py both         # (Windows + 한글 2022) 학회 샘플 위 투고본 hwp·pdf
python k23_repro_check.py          # k13·k14·k25·k18 재실행 재현성(약 35분)
python k21_raw_integrity.py        # (원자료가 있을 때만) 원자료 CSV 48개 해시·원자료→OD 재구성
```
시드: 무작위 비교경계 20260927(k13), N0 ΔIFR 20260924(k01). 같은 순서로 실행하면 csv는 바이트 단위로, json은 실행 시간 항목을 뺀 내용이 같다.

## 6. 공동연구자에게 부탁
1. 원고를 통독하고 논리 비약·표현을 지적해 주기(특히 Ⅱ 선행연구의 차별성 서술, Ⅴ.4 한계 넷째: 재배정과 가상경계가 같은 모듈성 기준을 쓰는 점).
2. 부록 표 A1의 48개 재배정 중 아는 지역이 있으면, 통행 외의 이유(학군·관할·정체성)로 현재 경계가 맞는 경우를 알려 주기.
3. 제목과 초록이 학회지 성격에 맞는지, 하정원 외(2024)·가상경계 방법 선행 논문과의 차별성이 충분히 드러나는지 의견.
