## 1. 주장 (한 문장)
2020~2025년 서울 기존 생활권의 내부통행률은 모든 자치구에서 높아졌지만 **경계가 좋아진 결과가 아니라 이동 범위가 좁아진 결과**였다(이웃한 동을 아무렇게나 묶은 무작위 경계도 같은 범위로 올랐다). 그 사이 기존 생활권과 데이터 기반 커뮤니티의 **불일치는 유의하게 줄지 않았고 내부통행률 격차는 벌어졌다.** 기존 생활권은 통행 기준으로 잘 그어져 있으며, **불일치는 소수의 경계 동에 집중되어 두 시점에서 같은 방향으로 반복된다.** 이 동들의 소속만 바꾸어도 기존 생활권은 커뮤니티 수준에 이른다.

## 2. 연구 질문 (Q1~Q3)과 원고 구성
1. **Q1** 기존 생활권의 IFR 상승은 경계가 좋아진 결과인가, 어떤 경계를 그어도 나타나는 변화인가?
2. **Q2** 같은 기간 기존 생활권과 실제 통행의 불일치는 줄었는가?

## 3. 자료·경계·지표
- 자료: 서울 생활이동 OD 2020년 1월·2025년 1월(도착 09:00~20:59, 집↔직장 통행 HW·WH 제외, 요일 전체, 서울 내부, 비공개 → 0), 행정동 424(2021년 코드표), 기존 지역생활권 116(면적 최대 중첩, 최솟값 0.51). 원자료 CSV 48개 해시·원자료→OD 재구성 검증 통과(k21).
- 경계: 기존 생활권(평가 대상) / 무작위 경계(자치구마다 1,000번 추출, N0 권역 수 · N1 + 권역별 동 수 · N2 + 통행량 비중(보조 분석), 최소 기준) / 데이터 기반 커뮤니티(자치구 안 Leiden 3,000회 종합, τ 0.5, 개수 = 기존 생활권, 비교 기준; 절차는 JTG 선행연구 Park et al., 2026에 바탕).
- 지표 — 식 (1) IFR = (같은 권역 안에서 끝난 통행량)/T, 식 (2) 내부통행률 격차 G = (a − b)/T, 식 (3) 불일치 D = (a + b)/T. T = 동에서 출발한 서울 내부 통행 전체, a = 커뮤니티만 권역 안으로 분류한 통행량, b = 기존 생활권만 권역 안으로 분류한 통행량. 항상 |G| ≤ D. 그 밖에 무작위 경계 대비 백분위, 모듈러리티 Q.
- **D와 IoU**: JTG에서 쓴 경계 일치도 IoU(행정동 수 기준 일대일 대응)와 D를 비교한다. 자치구 단위 선형 R²: 2020년 0.85, 2025년 0.79(두 경계가 같은 구를 빼면 0.75, 0.61), G는 R² ≤ 0.14. 같은 두 경계에서 나오므로 독립 검증이 아니라 "IoU가 동 개수로 재던 어긋남을 통행량으로 잰다"는 대응 관계로만 쓴다(변화 R² 0.67은 소수 구가 끌어올린 값이라 쓰지 않음).
- **IFR 분모 확정(저자 결정 2026-10-02)**: "동에서 출발한 서울 내부 통행 전체(같은 동 안 통행 포함)"를 채택한다. 이유: ① 세 경계가 모두 자치구 안에서 그어지므로 구를 넘는 통행은 어느 경계에서나 권역 밖으로 분류된다. 분모를 이 통행까지 포함한 서울 내부 전체로 두어야 세 경계의 IFR이 같은 통행량 위에서 비교된다. ② 같은 동 안 통행은 어느 경계에서나 권역 안이므로 경계와 상관없는 지표(동 안 통행 비율 18.4% → 21.1%)로 쓸 수 있고 "이동 범위가 좁아졌다"는 판단의 근거가 된다. ③ 기존 KPA 초안(2026-07~08)의 "같은 구 안 통행만·자기 동 제외" 분모로 계산해도 재배정 후 나아지는 방향은 같았다(2025년 기존 42.2%, 커뮤니티 46.0%, 재배정 46.7%; 원고 Ⅴ.5). 두 분모의 값은 섞지 않는다.

## 5. 결과 (확정값; 원고와 자동 대조됨, 40개 항목)
- ① IFR 기존 생활권 34.1 → 37.9%, 커뮤니티 34.8 → 39.4%, 25/25 구 상승. 기존 생활권 ΔIFR이 무작위 범위 안인 구 23/25. 유형 내 효과 98%(구성 2%), 7개 유형 모두 상승. 주말 30.9 → 35.3%, 평일 35.1 → 38.8%, 21/25 구 주말 > 평일(p < 0.001). 동 안 통행 비율 18.4 → 21.1%.
- ② D 8.5 → 8.3%(구 증가 13 : 감소 8 : 같음 4, p = 0.38). G 0.67 → 1.50%p(16 : 5 : 4, p = 0.027). G 변화 중 통행이 바뀐 부분 53%(순서에 따라 35~72%), 그 부분이 격차를 키운 구 16 : 5(p = 0.027).
- ③ 백분위 중앙값 N0 55/57, N1 97/97, N2 97/98. N1 대비 무작위 중앙보다 나은 구 24/25(p < 0.001). 생활권 75/78%가 같은 구의 무작위 동 묶음보다 IFR이 높음.
- ④ 재검토 후보 35/40개 동(전체 424개의 8~9%), 그 밖의 경계 동은 두 해 모두 0. 단계적 재배정 65개와는 다른 집합(교집합 31). **"불일치가 소수의 경계 동에 집중된다"의 근거는 이 8~9%가 아니라 ⑤의 결과(동의 15%를 옮겨 D의 60% 넘게 해소, 나머지 경계 동은 옮겨도 개선 없음)이다.**
- ⑤ 2025년 65개 동(20개 구) 재배정 → IFR 37.9 → 39.6%(커뮤니티 39.4%), D 8.3 → 3.2%. 2020년 65개 동(이동 66회), D 8.5 → 3.7%. 두 해 같은 재배정 48개. 2020 경계를 2025에 적용 시 22개 구 중 Q 19(p < 0.001), D 18(p = 0.004) 개선, 서울 전체 IFR 37.9 → 39.3%, D 8.3 → 5.1%. 광진구 사례 6개 동 +2.9%p.
- IoU–D: 위 §3.

## 7. 한정 (원고 Ⅴ.5와 본문에 유지)
- 통행 거리·시간의 감소를 직접 확인한 것이 아니다. D의 p = 0.38은 "유의하게 줄지 않았다"이지 불변의 입증이 아니다. G·D는 두 경계 사이의 상대적 결과이며 기존 경계의 계획상 부적합을 직접 뜻하지 않는다.
- 단계적 재배정 65개는 최소 변경이 아니며 계획상 효과를 검증한 것이 아니다. 재배정과 커뮤니티가 같은 모듈러리티 기준을 쓰므로 독립 검증이 아니다. 불일치가 반복되는 원인은 다루지 않았다.
- 두 시점(각 1개월), 비공개 셀 0, 자치구 안으로 한정, 무작위 경계 백분위는 표본 안의 순위, 부호검정은 자치구 독립 가정, N2는 서로 다른 경계가 1개인 구(금천구)가 있어 보조 분석. 권고는 통행만으로 본 검토 우선순위이며 학군·행정 관할·정체성은 고려하지 않았다.
