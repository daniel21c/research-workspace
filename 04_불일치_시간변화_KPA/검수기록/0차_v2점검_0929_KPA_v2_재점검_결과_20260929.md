# KPA v2 수정본 독립 재점검

점검 기준일: 2026-09-29
대상: 이번 메시지에 첨부된 공동연구자 ZIP, 제출본 ZIP, package ZIP. 대화에 남아 있는 최초 12쪽 PDF는 수정본 판단에 사용하지 않았다.

## 판단

이전 백분위 계산 오류와 재배정 집계 오류는 수정되었다. 추가 고정경계 평가의 주요 수치도 재현된다. 다만 표 6의 표본·판정 기준, 본문 자동검증의 실제 범위, 중간 반올림에 따른 2020년 D 표기 오류가 남아 있다. 검토용 공유는 가능하나 ‘모든 수치·해석 검증 완료’ 또는 즉시 제출 가능한 정본으로 확정하는 것은 이르다.

### 실행한 범위와 실행하지 않은 범위

실행: ZIP 내부 파일 해시 대조; 기존·수정 결과 비교; 단위시험 7+12개; 이동 이력 재생; 두 시점 OD의 동쌍 직접 집계; k14·k15 재실행; k18의 결과·연속성 검증 재실행; NetworkX의 별도 모듈성 계산; 표 6 표본·Mann–Whitney p값 재계산; 원고 숫자 변조에 대한 k19 반응 시험; DOCX 7개 표 셀 비교; 최신 익명 14쪽·저자정보 12쪽 PDF의 렌더 검토.

미실행: k13의 30분 규모 전체 무작위 분할 생성, k16·k17의 전체 실행, 원자료 CSV 48개에서 OD 재집계, Leiden 원천 도출, 한글 프로그램에서 HWP 재렌더, Git 저장소 계보 확인. 해당 항목의 패키지 내 기존 기록을 읽은 것과 직접 실행한 것을 구분했다. 원자료 48개는 현재 ZIP에 없다.

런타임에는 PyArrow/fastparquet가 없어 OD Parquet를 읽는 제한적 읽기 전용 디코더(parquet_audit_reader.py)를 사용했다. 해당 파일의 평면 스칼라 열, Snappy, PLAIN/RLE_DICTIONARY만 지원하고 다른 형식은 오류로 중단한다. OD의 행 수·동 수·통행 합을 확인했고, 이를 통한 k14 재실행 결과의 모든 수치·문자열은 저장 결과와 일치했다. 재실행 파일과 원본은 줄바꿈(CRLF/LF)을 정규화하면 동일하다. 원고·원본 ZIP은 덮어쓰지 않았다.

## 2. 필수 수정 A — 표 6의 첫 행과 공통 주석은 같은 표본이 아니다

원고 위치: 최신 익명 PDF 10쪽 표 6. 생성 코드: scripts/k18_v2_results.py의 T6(237~247행 부근). 자료: b5_dong_access.csv, b6_dong_attractors.csv, b7_similarity.csv.

표 주석은 권고 동을 ‘재배정된 동 중 원래 공식 생활권에서 바로 옮길 수 있던 동(2020 56, 2025 57개)’이라고 정의한다. 그러나 생활시설 Coverage 첫 행은 k15의 전체 재배정 동 65/65개에서 계산되고, 나머지 행은 k16·k17의 56/57개에서 계산된다.

| 첫 행 계산 방식 | 2020 A/B 표본 | 2025 A/B 표본 | p(2020) | p(2025) |
|---|---:|---:|---:|---:|
| 현재 실제 계산 | 65/240 | 65/239 | 0.601752 | 0.132882 |
| 주석과 동일하게 A를 제한한 확인 계산 | 56/240 | 57/239 | 0.199704 | 0.035827 |

동일 표본 확인 계산의 Coverage 차이 중앙값(A/B, %p)은 2020년 1.5462/0.9372, 2025년 1.6866/0.7825이다. 이 수치는 정본에 반영한 새 주결과가 아니라 표본 설명을 일치시켰을 때 무엇이 달라지는지 보여 주기 위한 진단이다.

2025년 p≈0.036을 이유로 관계가 입증됐다고 바꾸면 안 된다. 두 시점 모두 p<0.05라는 자체 기준을 충족하지 않고, 중앙값 격차도 1%p 미만이다. 표본을 p값에 맞춰 선택하지 말고 연구질문에 따라 결정해야 한다.

권장 최소 수정: 서로 다른 분석 표본을 유지한다면 각 행 또는 각 분석군에 A/B의 실제 n을 적고, 표 주석을 행별로 분리한다. 동일 표본으로 비교하려면 표본 제한의 근거를 먼저 확정한 뒤 표와 본문을 다시 생성한다.

### 판정 기준도 다르다

k15_access_link.py에는 생활시설에 대해 ‘A−B 중앙값 차 1%p 이상, 두 시점 모두 Mann–Whitney p<0.05, 10분 임계에서 방향 일치’를 사용한다. 현재 표 6 공통 주석의 ‘10%p 이상(또는 방향 일치)’는 이 첫 행의 기준을 정확히 설명하지 못한다. 시설 지표의 연속형 격차 기준과 역·상업시설 등의 비율 격차 기준을 분리해 적어야 한다.

### ‘내부 동’ 비교도 재분류가 필요하다

k15의 C군은 기하학적으로 옆 생활권과 접하지 않는 동이 아니라, ‘A에도 속하지 않고 초기 합법 단일 이동 목록에도 없는 동’이다. 패키지의 동일 인접 그래프에서 직접 확인한 결과 C군 119/120개 중 44/46개는 같은 자치구 안 다른 공식 생활권과 맞닿는다. 따라서 C군을 내부 동으로 부르며 ‘경계 동이 내부 동보다 크게 잃는다’고 해석할 수 없다. 기하학적 경계 여부와 이동 가능 여부를 별개 변수로 만들거나, C군을 잔여 비대상 동으로 명명하고 해당 비교 해석을 제거해야 한다.

근거: evidence/independent_metrics.json의 table6 및 boundary_definition; followup_checks.json의 same_gu_geographic_boundary; k15_access_link.py.excerpt.txt; k18_v2_results.py.excerpt.txt. 표 6 렌더: evidence/anonymous_page10_table6.png.

## 3. 필수 수정 B — k19는 원고 숫자가 틀려도 34/34 통과한다

k19_kpa_v2.py claims(md_text)의 수치 검사는 결과 파일과 코드 안의 고정 기대값을 비교한다. md_text는 뒤쪽 인용문헌 검사에만 사용한다. 즉 검사 이름과 달리 본문에 실제 적힌 숫자를 읽어 결과와 대조하지 않는다.

실제로 메모리상의 원고 사본에서 39.6을 99.9로(3곳), 48개를 999개로(4곳) 바꾼 뒤 같은 함수를 실행했다. 원래 원고도 34/34, 틀린 원고도 34/34 통과했고 검사 결과 전체가 동일했다. 원고 원본 파일은 수정하지 않았다.

지금의 시험은 ‘결과값 회귀시험’으로는 유효하지만 ‘본문 수치 자동 대조’의 근거는 아니다. 실제 원고·국영문 초록·시스템 입력문·PDF에서 수치와 문맥을 읽는 검사를 따로 둬야 한다. 표도 같은 잘못된 요약을 공유하면 모두 일치할 수 있으므로 표본·분모·반올림 출처 검사와 구분해야 한다.

필요 회귀시험: 본문 숫자를 의도적으로 바꾸면 반드시 실패할 것. 원고에서 주장 하나를 삭제해도 누락으로 감지할 것. 48/65가 다른 문맥에 나타나는 것만으로 통과하지 않도록 주장 ID와 연결할 것.

근거: evidence/mutation_original_results.json, mutation_altered_results.json, followup_checks.json; k19_kpa_v2.py.excerpt.txt.

## 4. 필수 수정 C — 2020년 D 8.6%는 이중 반올림의 결과다

b4_gu_summary.csv에서 자치구별 D×T를 합산해 직접 계산하면 2020년 재배정 전 D는 8.548919822533446%이다. 소수 한 자리로 바로 표시하면 8.5%다.

현재 k14는 요약 JSON을 만들 때 먼저 8.55로 반올림하고, k18은 그 숫자를 다시 소수 한 자리로 표시해 8.6을 만든다. 따라서 최신 표 5와 본문의 ‘8.6→3.7’에서 시작값은 표시 정밀도상 8.5로 바뀌어야 한다. 나머지 제시된 서울 IFR과 D의 한 자리 수치는 직접 반올림과 일치한다.

수정: 중간 결과와 검증 JSON에는 원정밀도를 보존하고 원고·표·그림 표시 단계에서만 한 번 반올림한다. k19의 하드코딩된 기대값도 함께 바로잡는다. 이 수정은 핵심 결론을 뒤집는 변화가 아니라 수치 표기의 실제 오류다.

근거: followup_checks.json의 rounding_from_saved_csv; k14_reassign.py.excerpt.txt.

## 5. 고정경계 평가의 가치는 인정하되 해석을 제한할 것

2020년에 재배정한 경계를 2025년에 재최적화하지 않고 평가하는 계산은 실제로 구현되어 있으며 수치도 맞는다. 같은 해에 최적화하고 같은 해에 평가한 결과만 있는 것보다 시간에 걸친 유지 여부를 더 직접적으로 보여 준다.

다만 이는 두 시점 결과를 이미 확인한 뒤 추가한 분석이다. 처음부터 분석 선택과 분리해 둔 미사용 평가자료라고 설명할 근거는 없다. 특히 D는 2025년 자료에서 도출한 LD2025를 비교 기준으로 사용하므로 외부의 독립적인 정답 경계와 비교한 것도 아니다.

권장 명칭: ‘2020년 재배정 경계의 2025년 고정경계 평가’ 또는 ‘사후 추가한 시점 간 적용 평가’. 권장 해석: ‘2025년 재최적화 없이도 일부 통행 지표의 개선이 유지되었다.’ 피할 해석: ‘순환성이 해결되었다’, ‘실제 경계 변경의 타당성이 독립적으로 입증되었다’.

현재 수정 원고의 한계 문구는 이러한 제한을 상당 부분 반영했다. 사용자에게 보고한 설명과 교수님께 보내는 메시지도 같은 수준으로 맞추면 된다.

## 6. 남아 있는 요약 문장·도식·기록

(1) 97%는 서울 전체를 하나의 무작위 경계 집합과 비교한 백분위가 아니라 25개 구별 N1 백분위의 중앙값이다. 초록·교수님 메시지는 ‘권역별 동 수를 맞춘 N1 대비, 구별 IFR 백분위의 중앙값이 약 97백분위였다’로 적는 것이 정확하다.

(2) 국문 초록, 논의, 결론, README의 ‘35·40개 동이 개선되며, 이를 차례로 적용한 재배정에서 65개’는 여전히 초기 단일 이동과 순차 재배정을 연결해 오해하게 한다. ‘별도의 모듈성 증가 기준 순차 재배정에서는 65개 동의 최종 소속이 바뀌었다’로 분리한다. 그림 1의 ‘나아지는 이동을 차례로’도 어느 지표인지 명시한다.

(3) ‘시설 접근성·주거 특성에서 차이가 없었다’는 ‘본 자료·지표·판정 기준에서 일관된 관련을 확인하지 못했다’로 제한한다. ‘주민참여·사업 집행의 연속성을 해치지 않는다’는 해당 효과를 직접 평가하지 않았으므로 결과로 단정하지 않는다. 서비스 포착 지표를 실제 시설 이용이나 개인 접근성 손실로 해석하지 않는다.

(4) N2는 출발 통행량 비중을 조건으로 사용한다. 모든 비교경계를 포괄하여 ‘이동 정보를 전혀 사용하지 않았다’고 쓰지 말고, 인접성 기반 생성과 통행량 비중에 의한 조건화를 구분한다. 비교 백분위는 해당 생성 방식·크기 조건에 대한 결과다.

(5) k23은 CSV는 바이트 비교, JSON은 seconds를 제거·키 정렬한 뒤 비교한다. ‘19개 파일이 모두 바이트 동일’보다는 이 구분을 적는다. 또한 19개 중 b8_verify.json은 k18 산출물인데 k23 실행 목록은 k13~k17이므로 k23 안에서 재생성되지는 않는다. k18 검증을 별도로 재실행하거나 k23에 추가해야 한다. 이번 점검에서는 k18 검증을 별도 실행해 통과했다.

(6) 두 해 모두 이동한 동 ID는 50개이고 같은 최종 재배정은 48개다. k16의 보조 ‘두해공통’ 지표는 여전히 동 ID 교집합을 사용한다. 그림 3의 ‘한 해’ 범주에도 두 해 모두 이동했으나 최종 목적지가 다른 2개 동이 들어간다. 보조 목록·범례를 목적지 일치 여부에 맞춰 정의하거나 이름을 바꿔야 한다. 핵심 A1의 48행은 올바르다.

(7) 영문초록은 공백 분리 237단어(체크리스트에는 215단어)다. 이를 규정 위반으로 판단한 것은 아니며 체크리스트의 현재 원고 반영 여부 문제다. AI 사용 기간도 최신 수정 작업이 9월 28일에 이루어졌는데 본문은 9월 23~27일로 남아 있다. 실제 도구·버전·작업기간과 검토 범위를 로그로 확인해 갱신한다.

## 7. 파일·렌더 상태

새 익명 PDF 14쪽, 저자정보판 12쪽은 실제 페이지 수와 일치한다. DOCX 7개 표는 생성 사양과 맞는다. 렌더 접촉 시트와 관련 페이지에서 이전에 보고된 큰 글자 겹침은 확인되지 않았다. 다만 익명판의 표 3/표 4와 설명 주석은 각각 다음 페이지로 갈라지고, 부록 2절 제목과 표 A1도 페이지가 갈린다. ‘표 제목 분리 해결’과 ‘모든 표·주석 배치 최적화’는 다른 완료 항목이다.

PDF 단순 문자열 검사에서 페이지 경계·러닝 헤더가 끼어드는 일부 문장 조각이 검출되었다. 해당 조각은 페이지 전후에 존재함을 텍스트·렌더로 확인했으며 실제 누락으로 판정하지 않았다. 본 점검은 한글 원본을 다시 렌더하거나 모든 좌표를 완전 검증한 것은 아니다.

학회 샘플의 2018/Vol.53 및 00/2000 머리말·꼬리말이 남아 있다. 템플릿 유지인지 제거 대상인지는 최종 서식 확인 때 구분한다. 저자정보 포함판을 심사용 업로드 묶음에 잘못 넣지 않도록 현재 분리 구조를 유지한다.

## 8. 기존 KPA 정본과 v2의 분석대상은 구분할 것

이 프로젝트의 기존 기준은 same-gu, non-self-loop 통행 분모와 G·D_flow의 분리다. 이번 v2는 자기 동 내부통행을 포함한 서울 내부 전체 통행을 분모로 쓰고, 구 간 통행은 모든 경계에서 외부로 분류한다. 연구질문도 분류차 진단에서 무작위 경계·재배정 중심으로, 서비스 분석도 두 시점 비교로 바뀌었다. 따라서 기존 정본의 단순 교정본으로 취급할 수 없다.

기존 규칙의 지표: T*=sum w_ij·1[g(i)=g(j), i≠j], IFR*=sum w_ij·1[g(i)=g(j),i≠j,z(i)=z(j)]/T*.
v2 지표: T=sum_{i,j∈서울} w_ij, IFR=sum w_ij·1[z(i)=z(j)]/T.
어느 규칙에서도 G=IFR_LD−IFR_LZ이며, D_flow는 두 경계의 내부/외부 판정이 다른 통행의 비율이다. |G|를 D_flow로 쓰지 않는다.

같은 최신 패키지의 2025년 OD와 경계에 분모만 달리 적용한 확인 계산은 다음과 같다.

| 분모 | 공식 IFR | 이동경계 IFR | G | D_flow |
|---|---:|---:|---:|---:|
| v2 서울 전체·self 포함 | 37.858705% | 39.357738% | 1.499032%p | 8.333726% |
| same-gu·non-self | 42.237749% | 46.018359% | 3.780610%p | 21.017938% |

이 표는 기존 v5/v11 validation을 재현한 값이 아니라 현재 업로드된 OD·경계에 두 분모를 적용한 감사 계산이다. 원고의 37.9% 등을 기존 정본의 같은 지표 값인 것처럼 섞으면 안 된다. v2를 채택한다면 연구질문·분모·본 분석/민감도·서비스 분석 범위의 변경을 명시하고, 기존 정본과 다른 후보로서 교수님과 확인해야 한다. 이번 ZIP에는 Git 계보를 확인할 저장소가 없어 정본 승격 여부는 확인하지 않았다. 422개 엄격 일치 민감도의 연결 여부도 이번 패키지만으로 확정하지 않았다.

## 완료 순서

우선 표 6의 표본과 판정 기준을 확정한다. 이어서 기하학적 경계와 이동 가능 여부를 분리하고, 요약값을 원정밀도로 저장한다. 실제 원고 숫자를 읽는 검사와 의도적 오류 회귀시험을 추가한 뒤 표·초록·본문·README·교수님 메시지를 한 번에 갱신한다. 그 후 DOCX/HWP/PDF를 같은 소스에서 생성하고 숫자·표본·분모·렌더·파일 해시를 각각 확인한다. 커밋·푸시·투고·외부 전송은 이번 점검에서 수행하지 않았다.
