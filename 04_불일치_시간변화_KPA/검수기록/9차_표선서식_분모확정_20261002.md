# 9차: 표 선 서식과 IFR 분모 확정 (저자 결정 2026-10-02)

## 표 선 서식
학회 국문샘플(`templates/kpa_sample_20260122ver.hwp`)을 PDF로 렌더링하고 표 셀의 테두리 정의를 읽어 확인했다.

| | 학회 샘플 | 반영 |
|---|---|---|
| 세로선·좌우 바깥선 | 없음(흰색/None) | 없음 |
| 가로선 | 행마다 0.1mm 실선 | 0.1mm 실선 |
| 머리행 | 회색 바탕 | 회색 바탕 |
| 셀 정렬 | 첫째 열 왼쪽, 나머지 가운데 | 같음 |

구현: `code/k22_hwp_kpa.py`의 `_kpa_table_lines`(HCellBorderFill), 검토용 docx는 `code/k06_kpa_submission.py`의 `borders`. 같은 시점에 배치 점검이 "Figure" 캡션을 인식하지 못하던 문제도 고쳤다.

## IFR 분모
"동에서 출발한 서울 내부 통행 전체(같은 동 안 통행 포함)"로 확정. 근거는 `../연구설계.md` §3: ① 세 경계가 모두 자치구 안에서 그어지므로 같은 통행량 위에서 비교, ② 같은 동 안 통행은 경계와 상관없는 지표(18.4% → 21.1%), ③ 기존 KPA 초안 분모로 계산해도 재배정 후 개선 방향이 같음(2025년 42.2% / 46.0% / 46.7%).
