# KPA review_r1 재심 의견 — 2026-09-29

## 판단

시설 관련 핵심 보완 요구는 대부분 실질적으로 반영되었다. 종합 Coverage의 측정 대상, 행별 비교집단, 목표 권역 선정, 범주별 분포, 동일 집단 민감도, 자료 출처와 한계, 세 구조 대비 사례가 서로 연결된다. 교수님 검토용으로 공유할 수 있으며, 이번 확인에서는 시설 계산이나 연구설계를 다시 구성해야 하는 새로운 근거를 찾지 못했다. 실제 학회 게재 판정이나 기존 KPA 정본의 대체 승인을 뜻하지 않는다.

시설 분석은 기존 공식 경계에서의 잠재적 시설 포착 차이를 설명하는 탐색적 보조 분석이다. 재배정 후 접근성 개선, 실제 이용·수용력·서비스 충분성, 인과효과를 평가하지 않는다.

## 심사 의견의 반영 상태

1. L=COV경계없음−COV공식, δ=median(A)−median(B)를 명시하고 재배정 경계의 개선치와 분리했다.
2. 7범주의 평균·중앙값·사분위범위, 서울 인구가중 도달률을 추가해 단순평균과 중앙값, 인구가중 통계를 구별했다.
3. 일상소매 제외와 연결시간 포함을 동일 A/B로 비교했다. 전자는 소매 범주 전체를 삭제하지 않고 다른 소매 유형과 7범주 평균을 유지한다. 두 설정 모두15분이며10분 결합 결과는 계산하지 않았음을 공개했다.
4. 표6B에서 A와B 목표 선정 방식, 원래 공식 경계에 의한 시설/구성 집계, 직선거리, 유사성 변수·표준화·자기동 제외, 양쪽 시설 부재 처리를 공개했다.
5. 공간·생활권 의존성을 보정하지 않은 검정은 참고값으로 제한하고, 동일 동 두 시점의 반복을 독립 재현으로 해석하지 않았다. 탐색적 기술비교에 한정하는 한 복잡한 회귀모형의 추가를 필수로 요구할 이유는 줄었다.
6. 세 사례가 통행 진단의 독립/순차 경로와 기존 공식 경계의 범주별 시설 차이를 연결한다. 현지 사실이나 실제 경계 변경 권고를 만들지 않았다.

## 남은 한정적 수정

### 1. 국영문 초록의 대리성 표현 일치

영문 “candidate status is therefore insufficient as a proxy for facility-capture problems”는 대리성 자체를 부정하는 것으로 읽힐 수 있다. 국문의 근거 부족 수준에 맞춰 다음을 권한다.

“The comparisons did not provide consistent evidence to support using mobility-based candidate status as a proxy for facility-capture gaps under the existing official boundaries.”

분류성능이나 대리변수 타당성을 직접 검증한 연구로 확대하지 않는다. 본문에서도 현재 자료·집단·지표·비교조건에 한정한다.

### 2. 검토 총본과 투고 본문을 구분

43쪽은 단일 열 검토용이며 학회 조판 분량과 같다고 간주하지 않는다. 현재 총본은 보존하고, 투고용에서는 결과표를 줄이기보다 본문과 세부 자료의 위치를 조정한다. 본문에는 주연구 결과, 표6A 핵심 요약, 세 사례를 묶은 짧은 비교표를 남긴다. 7범주 전 조건 분포, 전체 출처 명세, 시설 부재·자치구별 전체 표와 재현 기록은 부록 또는 학회가 허용하는 보충자료로 정리한다. 표6B의 본문 잔류 여부는 해당 논리의 필요성에 따라 교수님과 결정한다. 사후로 불리한 결과를 숨기는 편집은 하지 않는다.

### 3. 부록 표의 번호·단위·명칭

A3(4개), A4(2개), A5(8개 범주), A8(2개)의 별도 표에 같은 번호를 반복하므로 A3a–d 등의 패널 표기나 연속표 체계를 사용한다. Table6A/6B와 부록의 영문 제목도 기존 표와 같은 편집 체계로 통일한다. A2의 의료6유형과 행정·안전2유형은 JSON의 분류와 맞지만, 보건소·보건지소와 소방서·119안전센터가 각각 한 유형임을 세미콜론이나 묶음 표기로 표시한다. 모든 결과를 네 자리로 제시하기보다 본문은 읽기 쉬운 정밀도로, 상세 결과는 부록/CSV에 보존한다. 이 과정에서 원정밀도 결과 자체를 바꾸지 않는다.

### 4. 운영체제 간 검증

동일 Windows 환경에서의 바이트 재현과 다른 운영체제에서의 값 재현을 구분한다. 경로는 저장 시 POSIX 상대경로로, 읽을 때 Windows 구분자를 처리하도록 한다. CSV/JSON 줄바꿈을 명시적으로 LF로 저장하거나, 기존 원본 보존 후 의미 기반 비교를 별도 제공한다. 이 변경으로 기존 해시·검증기록을 조용히 덮어쓰지 말고 새 패키지 판으로 관리한다.
