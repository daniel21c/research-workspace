# AG 확정본 공동연구자 패키지 (2026-10-02 기준, 데이터 사용 정합 감사 반영본)

**논문**: Following trips, keeping services: Mobility-guided reassignment of boundary dongs in Seoul’s living-zone plan and within-zone walkable service coverage (Applied Geography 투고용). 한국어 제목: 통행을 따르며 시설을 지키다 — 서울 생활권계획 경계 동의 통행 기준 재배정과 생활권 안 보행 시설 포착

**어디에 놓인 연구인가**: JTG 논문(Park, Eom & Lee, 2026)은 이동 커뮤니티로 공식 생활권 116개를 벤치마크해 어디가 불일치하는지 찾았고, KPA 논문은 그 불일치가 일부 경계 동에 몰려 있어 그 동들만 인접 생활권으로 재배정해도 자족성(IFR)이 올라간다는 것을 보였다. 이 논문은 그 다음 질문이다.

**질문**: 통행에 맞게 경계 동을 재배정하면 자족성은 올라가는데, 주민이 걸어서 쓰는 시설(27종 7범주)은 그 생활권 안에 남는가?

**답(두 해 모두)**: 총량으로는 남는다. 통행 기준(모듈성) 재배정은 자족성을 높이면서 생활권 밖에서만 시설에 닿는 주민의 총수를 줄였고, 같은 횟수의 무작위 재배정 100경로는 예외 없이 늘렸다. 다만 그 감소는 시설이 드문 문화·행정·안전에서 나왔고, 나머지 다섯 범주에서는 통행 기준도 누락을 늘렸다(무작위보다 덜). 공식 생활권은 규모·모양을 맞춘 대안 지도 거의 전부보다 낫다. 경계 동의 통행은 걸어서 닿는 의료·소매·생활서비스가 더 많은 인접 생활권으로 향하지만, 이 관계는 누락이 줄어든 범주에서 약해 감소의 이유가 되지 않는다. 결과는 생활권 수를 고정하고 인구·모양 제약을 두지 않은 재배정에서 나왔고, 두 제약을 함께 걸면 2025년에는 뒤집혔다(부록 Table A.3). 그래서 "기존 생활권의 조정"에 한정했다.

## 2. 분석의 틀

- **입력(연도마다 고정)**: 424동, 공식 116생활권, 서울 생활이동 OD(1월, 09–20시 도착, 집–직장 통행 제외), 100 m 인구 격자, 직접 구축 시설 27종 7범주, OSM 보행망(15분, 4 km/h). 2020·2025 두 해.
- **지표 둘**: IFR(내부통행률, internal flow ratio), L(누락 인구: 어떤 범주 시설에 걸어서 닿지만 자기 생활권 안에서는 닿지 않는 주민 수; 집계 지표). 범주별·5범주·시점 등급 C 제외 L은 `code/a10_sensitivity.py`.
- **비교 기준 셋**: (a) 경계 동 무작위 재배정 100경로, (b) 규모·모양을 맞춘 대안 생활권 지도 1000장(선거구 앙상블 ReCom), (c) 같은 경계 동의 여러 인접 생활권.

## 3. 핵심 결과(두 해 모두 성립, 2020 / 2025)

1. **Q1** 통행 기준 재배정은 자족성을 올리면서(2025 IFR 37.9%→39.6%) 누락 총량을 줄인다: 경로 끝 −61,615 / −45,237명. k = 18 / 15부터 모든 단계에서 무작위 100경로 전부보다 낮다. 무작위 100경로는 예외 없이 늘린다(중앙값 +216,360 / +290,894명).
2. **Q1 범주별**(Table A.4): 감소는 문화(−40,533 / −25,564)와 행정·안전(−27,090 / −25,339)에서 나온다. 교육은 늘고(+10,893 / +27,872) 나머지는 ±1,500명 안. 5범주로 세면 통행 기준 +7,403 / +28,558, 무작위 중앙값 +47,392 / +67,198(통행보다 높게 끝난 무작위 98% / 96%)(Table A.5).
3. **Q1 시점 민감도**(Table A.5): 시점 등급 C 세 유형(공공도서관·주민센터·소방서·119안전센터)을 빼면 행정·안전 범주가 통째로 빠지지만, 통행 기준 −44,597 / −6,072, k = 18 / 17부터 무작위 전부보다 낮다.
4. **Q1 제약**: 인구 ±20%·모양 제약을 함께 걸면 −26,182 / +43,091로 2025년에 부호가 뒤집히고 경로는 22회에서 끝난다(Table A.3).
5. **Q2** 공식 생활권은 대안 지도 1000장 중 998 / 1000장보다 누락이 적다(5범주 999 / 1000, C 제외 995 / 1000). 대안 중앙값보다 159,592 / 201,810명 적다.
6. **Q3** 경계 동의 통행은 걸어서 닿는 시설이 많은 인접 생활권으로 향한다(편상관 0.084 / 0.118). 의료·소매·생활서비스에서 강하고, 교육·보육은 0 근처, 문화·행정·안전은 약하다. 그래서 Q1의 감소를 설명하지 않는다.

## 5. 한계(원고 5.4)

생활권 안 시설 포착은 집계 지표이며 실제 이용·후생이 아니다. 한 도시·두 시점이고 기술적 결과이며 인과 검정이 아니다. 대안 지도는 균등 표본이 아니며 네 개 구는 대안이 매우 적다. 시설 목록은 재구성한 것이다(2020 기록의 98.3%·2025의 88.0%가 현재 인허가 이력 역산, 일부 공공 명부는 기준 시점 근처 판, 2020 일상소매는 재생성 자료). OD의 3명 미만 비공개 값은 0으로 두었다(2020년 1월 서울 내부 기록의 24.1%, 통행량 상한 약 12%). 통행 기준 재배정은 인구·모양 제약을 두지 않았다. 설계는 탐색 뒤 정했으므로 사후 분석으로 보고한다.
