## 1. 핵심 질문과 주장

**질문**: 이동 자료로 생활권 경계를 고쳐도, 주민이 걸어서 쓰는 시설이 생활권 안에 남아 있는가?

**주장(한 문장)**: 서울 두 시점에서 시험한 모듈성 규칙(생활권 수 고정, 인구·형상 조밀도 제약 없음)으로 경계 동을 재배정하면 경로 끝의 경계 내 보행 서비스 누락 총량이 줄고, 같은 횟수의 무작위 경로 100개는 모두 늘었다. 인구·형상 조밀도 제약을 함께 두면 2025년에는 유지되지 않는다. 공식 생활권은 표본으로 뽑은 규모·모양 조건 대안 지도 거의 전부보다 누락이 적다. 경계 동의 통행이 보행 시설이 많은 인접 생활권으로 향하는 것은 앞 결과와 부합하는 공존 양상이며 그 기제를 입증한 것은 아니다. 경계를 고칠 때는 통행 포착과 서비스 포착을 함께 점검해야 하며, 경계 조정이 전면 재설계보다 나은지는 검증하지 않았다.

**네 가지 답(두 해 모두 성립)**
1. 경계 동을 무작위로 재배정하면 누락이 늘어난다(65~66회 이동 후 중앙값 +22만~+29만 명).
2. 통행 기준(모듈성) 재배정은 경로 끝의 누락 총량을 줄인다(−61,615 / −45,237명, 2020 / 2025; 생활권 수 고정, 인구·형상 조밀도 제약 없음). k = 18 / 15부터 모든 단계에서 무작위 100경로 전부보다 낮다. 옮긴 인구는 무작위와 비슷하다. 인구·형상 조밀도 제약을 함께 두면 2020 −26,182 / 2025 +43,091(원고 5.2·A3).
3. 공식 생활권은 크기·모양을 맞춘 대안 지도 1,000장보다 누락이 적다(2025 1,000/1,000, 2020 998/1,000). 대안 중앙값보다 16만~20만 명 적다.
4. 경계 동의 통행은 걸어서 닿는 시설이 더 많은 인접 생활권으로 향한다(편상관 0.08 / 0.12, 도달 면적·인구 통제). 의료·소매·생활서비스에서 강하고 교육·보육은 0 근처. 답 1·2와 부합하는 공존 양상이며 그 원인을 입증한 것은 아니다.

정확한 값은 `results/`와 원고 자동 기입값 `manuscript/values_used.json`이 기준이다.

## 3. 원고 구성 (AG 형식)

서론 → 선행연구(2.1 서비스 공급 단위로서의 생활권[연구1의 "묶음 공급 단위" 논리], 2.2 기능지역·통행 기반 구획, 2.3 접근성 측정의 경계 문제, 2.4 대안과 비교하는 계획 평가[선거구 앙상블], 2.5 연구 질문) → 자료 → 방법 → 결과(5.1 공식 생활권, 5.2 무작위 vs 통행, 5.3 대안 지도 속 위치, 5.4 통행이 향하는 곳) → 논의(함의·한계) → 결론.

- 초록은 구체적 숫자 없이 간결하게(≤250단어). 하이라이트 5개(≤85자), 주제어 7개. 이중 익명(제목 면 별도).
- 용어: "within-zone service coverage", "excluded population". 메커니즘은 "통행이 향하는 곳에 시설이 있다"(공존)로 쓰고 인과("따라간다")로 쓰지 않는다.
- 인용: JTG(Park, Eom & Lee, 2026)는 3인칭 인용. KPA는 미투고라 참고문헌에 넣지 않고 투고 편지에만 언급. 연구1은 별도 논문으로 두고 논리만 빌리며, 단위 크기 사다리는 연구1 T5와 겹치므로 다루지 않는다.

## 4. 본문에서 뺀 것과 한계(원고 6.4·부록 A3에 공개)

- SIZE20 인구 제약을 건 모듈성 재배정: 끝 ΔL 2025 +43,091, 2020 −26,182(부호가 해마다 다름) → 부록 A3와 한계 한 줄.
- IFR 직접 최대화 탐욕: +52,017 / +47,877(2025 / 2020) → 부록 A3.
- 대안 지도 전체의 계획 단위 상관 ρ(IFR, L | 모양) −0.12 / −0.13 → 부록 A3만.
- 2020 메커니즘에 생활권 규모 통제를 더하면 0.065 [−0.012, 0.146]로 0 포함 → 본문 결과와 한계에 그대로 적음.
- 쌍 차분 ΔIFR ~ ΔMAI(v1): 무작위 계획 98~100%가 같은 부호(경계 회계 인공물) → 폐기, 부록 A3 한 줄.
- 사후 분석임을 방법 4.4와 한계에 명시. 인과 주장 금지, "LD가 더 좋다" 주장 금지. 메커니즘(답 4)은 '공존과 부합'까지만 쓰고 답 1·2의 원인으로 쓰지 않는다. 답 1·2는 '생활권 수 고정·인구 제약 없음' 조건을 초록·결론에 붙인다(인구 ±20% 제약 시 2025년 부호 반전).
- 기타 한계: 한 도시·두 시점(연도 간 비교는 추세 아님), 앙상블 비균등·4개 구(종로·중구·서대문·금천) 합법 분할이 매우 적음(전수 열거 1~8개, 2020 서대문 대안 1개 미방문), OD 비공개 0·HW 제외, OSM·스냅, 15분 기준.
