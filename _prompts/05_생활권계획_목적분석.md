3. **코딩**. 코딩 틀은 아래 6개다(사례표의 5분류 + 1). 문장마다 해당 코드를 붙인다(복수 허용).
   - (가) 접근성·형평: 시설 도달, 취약지 해소, 균등 공급
   - (나) 행정 효율·자원배분: 예산 단위, 사업 조정, 실행력
   - (다) 참여·협의: 주민 참여, 이해관계 조정
   - (라) 통계·모니터링: 진단 단위, 지표 관리
   - (마) 협력·정체성: 권역 간 협력, 공동체 의식, 장소성
   - (바) 이동·생활 실태 반영: 실제 통행권, 보행권, 일상 행동 범위
   - 코딩북(`코딩북.md`)에 코드 정의, 포함·제외 예문을 쓴다. 1차 코딩은 이 대화가 하고, 사용자가 2차 독립 코딩을 할 표본(문장 20% 이상, 무작위, seed 기록)을 `data/coding_sample_for_user.csv`로 따로 낸다. 두 코딩의 일치도(Cohen's κ)는 사용자 코딩이 들어온 뒤 계산한다. 혼자 코딩한 결과를 최종으로 쓰지 않는다.
4. **텍스트마이닝(보조)**. 한국어는 kiwipiepy(없으면 KoNLPy), 영어·프랑스어·일본어·중국어는 각 언어 처리기 또는 영어 번역본에 spaCy. 문서별 목적 문단의 명사구 빈도, 코드별 문장 비율, 국내/해외 상위 키워드 비교, 문서 간 공출현 네트워크. 코드는 자기 폴더 `code/`에, 결과는 `output/`에. 숫자는 모두 코드 출력에서만 가져온다.

   - 그림: 국내/해외 키워드 비교, 코드 비율 막대(도시별)
