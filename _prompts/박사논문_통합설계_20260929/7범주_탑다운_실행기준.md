## 3. 지표·분모·유효범주

`u`는 평가단위, `o`는 출발격자, `p_o`는 인구, `b`는 경계조건, `c`는 범주, `J_b(o,c)`는 임계 내 도달 가능한 c시설 격자다. 경계 제약은 **출발·도착 격자의 소속 조건**이며 보행경로 전체의 내부 통과를 강제하지 않는다.

| 지표 | 계산·분모·결측 처리 |
|---|---|
| COV | `r_b=1[J_b가 비어 있지 않음]`; `COV_b(u,c)=Σp_o r_b/Σp_o`. 분모는 전체 평가인구. 본 종합은 **7범주 단순평균**, 0~1. ΔCOV는LD−LZ의 종합값 차 |
| MAI | `m_b(o,c)=max_{g∈J_b} 동시입지 범주수`. 미도달은미정의. 범주별 `Σ(도달인구×m)/Σ도달인구`; 종합은 값 있는 범주 단순평균, 본 **1~7**. 도달인구·유효범주 수를 함께 저장하고 결측을0으로 바꾸지 않음 |
| ΔMAI | 두 경계 모두 유효한 **같은 범주**의 `MAI_LD−MAI_LZ`를 평균. 서로 다른 유효범주의 종합MAI끼리 빼지 않음. 공통유효범주가 없으면NaN, `n_cat_dMAI` 저장. 정본 `a06c_delta.py` |
| 시점 공통4 | `temporal_common4`의4는 **2시점×2경계 네 셀**. 네 셀 공통유효범주에서 `(LD_1−LZ_1)−(LD_0−LZ_0)` 평균. 범주를4개로 줄이는A4와 다르며 기본 두경계ΔMAI를 대체하지 않는 민감도 |
| PWATT | 15분 안에 도달한 인구만의 최근접시간 가중평균. 30분 상한평균·전체인구 평균과 구별 |
| 2SFCA | 시설수/도달수요를 두 단계로 배분, `ΣpA/Σp×10,000`. 전체인구 분모·인구1만명당시설수. 시설미도달주민A=0, 수요0시설은미할당으로 기록. 시설수는정원·용량이 아님 |
| 집계·미정의 | 상위공간은 원량 합산 후 분자합/분모합. 범주평균은 그 뒤 정의대로 계산. 인구분모0·MAI도달분모0·OR분모0을0으로 채우지 않고 해당 수·사유를 보고 |

공통MAI는 범주별 조건부평균을 다시 평균한다. AG 코드가 보조값으로 인구×범주를 함께 묶어 평균한다면 다른 집계이므로 별도 이름·분모로 명시한다. 이를 공통MAI 결과로 바꾸어 표기하지 않는다. AG 주지표 L은 ‘무경계에서는 도달하나 해당 경계에서 하나 이상 범주가 누락되는 **고유 인구**’이며7범주의 인구를 중복 합산하는 값이 아니다.

## 6. 설계 → 코드 → 재실행 → 원고 → 패키지

1. **공통 설계:** 중앙 README·연구설계의 현행 구절, 이 기준, 배포 지문을 맞춘다. 실제 검증 후에만 상단을 적용완료로 바꾼다.
2. **연구별 설계:** 각 담당이 자기 폴더에서 질문·범주·변수·표본·모형/시나리오·표/그림·검증의 연결을 확인한다. JTG는 시설 의존성이 없어 주분석 변경이 없다는 점도 명시한다. 이전 설계는 이력으로 보존한다.
3. **코드:** 설계가 요구하는 집합·유효범주·분모·지문을 구현·확인한다. 본A7, 민감도A4, B4, 연구1 공공7유형을 각각 검사한다. 상류 코드나 배포자료를 연구 폴더에서 고치지 않는다.
4. **재실행:** 연구별 승인 범위에서 동결 입력으로 새 결과를 생성한다. 이미 완료한 동일 입력·동일 정의의 실행은 해시와 검증으로 재사용 가능 여부를 판단하고 불필요하게 중복하지 않는다. 불일치가 있는 하류 결과만 영향 범위에 맞춰 다시 실행한다.
5. **원고:** 새 결과의 표·그림·본문·초록·부록에서 판본·범주·분모를 일치시킨다. 옛8범주의 수치와 새7범주 수치의 차이를 실제 시점 변화로 읽지 않는다. 보류·한계는 과학적 한계로 설명하되 작업 상태 문구를 논문 본문에 남기지 않는다.
6. **패키지:** 설계·실행코드·환경·최소입력의 출처/해시·결과·검증·재현방법을 연결한다. 연구별 완료 상태는 각 담당이 증거에 따라 기록한다. 공통 설계 적용 완료만으로 연구결과·원고·패키지 완료를 주장하지 않는다.
